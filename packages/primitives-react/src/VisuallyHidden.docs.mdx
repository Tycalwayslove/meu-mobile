# VisuallyHidden

## 当前能力

- 固定渲染原生 `span`，透传 span 的原生 HTML/ARIA 属性。
- 使用 1×1、overflow、legacy clip 和现代 clip-path 组合隐藏视觉内容。
- 不设置 `hidden`、`display: none`、`visibility: hidden` 或 `aria-hidden`，内容保留在 accessibility tree。
- 保留 caller class，并在 forced-colors 模式维持裁剪规则。
- `focusable=true` 时仅在自身或后代未聚焦时裁剪，可用于键盘聚焦后显现的 skip link；组件不会擅自创建 Tab stop。
- 支持 React ref；SSR 输出完整文本与语义属性，`focusable` 不会泄漏为无效 DOM 属性。

当前状态为 `verification`；尚未完成 Windows High Contrast、VoiceOver/TalkBack 真机验收，不能标记为 commercial。

## 何时使用

用于给纯图标按钮补 accessible name、为视觉图表补说明，或提供 `role="status"` 的读屏状态文本。`focusable` 模式只用于跳至主要内容等在键盘聚焦后必须可见的入口。文字应简短、与当前 locale 一致并随状态同步。

## 何时不要使用

- 不用来隐藏敏感信息、SEO 堆词或应对所有用户可见的错误。
- 默认模式不包裹 Button、Link、Input；视觉不可见的可聚焦控件会形成键盘陷阱。需要 skip link 时必须显式使用 `focusable`，并验证聚焦后入口完整可见。
- 可见 label 更清晰时，不应只提供读屏 label。

## 结构与状态

结构只有一个 `span` 和 children。默认状态永久裁剪；`focusable` 状态在自身或后代获得焦点时解除裁剪。内容可以承载静态名称、描述、live region 或 skip link，但 live region 的更新策略由调用方负责。

## 基础用法

```tsx
<button type="button">
  <MeuIconSearch aria-hidden />
  <VisuallyHidden>搜索订单</VisuallyHidden>
</button>
```

```tsx
<VisuallyHidden role="status" aria-live="polite" aria-atomic="true">
  已加载 20 条订单
</VisuallyHidden>
```

```tsx
<VisuallyHidden focusable>
  <a href="#main-content">跳至主要内容</a>
</VisuallyHidden>
```

## 受控与非受控

不适用。组件不持有状态；children 和 ARIA 属性由调用方控制。

## 表单集成

可作为表单控件可访问名称或描述的一部分。优先使用显式 `<label>`；需要 `aria-describedby` 时给 VisuallyHidden 稳定 `id`。验证错误若会影响所有用户，仍应可见展示。

## Props

接受 `HTMLAttributes<HTMLSpanElement>`，包括 children、id、role、aria-live、tabIndex 和 className。`focusable=false` 默认永久裁剪；设为 true 时仅在自身与后代均未聚焦时裁剪。该属性不自动添加 tabIndex，API 表以 TSDoc/API Extractor 为准。

## Events

透传 span 原生事件，但组件不应作为交互目标。读屏 live region 的 announcement 时机由浏览器和辅助技术决定，不等同于 DOM event。

## Ref 与命令式方法

ref 指向真实 `HTMLSpanElement`，可用于测试、关联或明确的焦点恢复。不要通过 ref 把默认模式下的隐藏说明变成临时交互入口。

## 键盘操作

| 按键          | 行为                                                                                            |
| ------------- | ----------------------------------------------------------------------------------------------- |
| Tab           | 默认模式不创建 Tab stop；`focusable` 模式由 caller 提供的交互后代或 tabIndex 接收焦点并解除裁剪 |
| Enter / Space | 沿用获得焦点的原生交互元素行为；wrapper 不合成 click                                            |

## 触摸与手势

不适用。组件没有可点击面积，不应承载触摸操作。

## 无障碍

组件的核心契约是视觉隐藏但保留读屏可达性。caller 必须避免同时设置 `aria-hidden`、`hidden` 或空内容。纯图标按钮中的可见 SVG 应使用 `aria-hidden`，避免图标和隐藏名称重复命名。

## 动效

不适用。组件没有动画，reduced-motion 不改变行为。

## 主题与定制

没有 Token。默认裁剪同时限制 width/height、min/max 尺寸、box-sizing、overflow、legacy clip、clip-path 与 white-space，降低全局 span/reset 样式导致文字泄漏或布局占位的风险。`className` 会合并，但 caller 不应覆盖这些属性；带 `!important` 的全局 CSS 仍可能破坏契约。

## SSR 与 Next.js

无浏览器全局和 effect，服务端直接输出 span 与文本，hydration 结构一致。`focusable` 只选择 CSS class，不输出无效 DOM 属性。可在 Server Component 输出中使用其生成的静态标记，但包入口的具体 Client/Server 边界仍以构建产物为准。

## RTL 与国际化

裁剪逻辑与方向无关。隐藏文案必须来自当前 locale；数值、顺序和状态词不能只复用视觉缩写。必要时可透传 `lang` 和 `dir`。

## 浏览器与 WebView

legacy `clip` 与 `clip-path` 并存，覆盖旧 WebView 和现代浏览器；forced-colors media rule 防止高对比模式重置导致文本泄漏。源码通过 Chrome 70 语法门禁，真实 Windows High Contrast、iOS 13 VoiceOver 和 Android TalkBack 待测。

## 边界情况与已知限制

- className 可覆盖隐藏样式，属于调用方责任，不是稳定主题接口。
- 极端全局 CSS 使用 `!important` 仍可能破坏裁剪。
- 组件不会自动去重 accessible name，也不会验证 live region 文案频率。
- `focusable` 只负责聚焦显现，不提供目标存在性、滚动、焦点转移或路由管理；完整 skip link 仍由应用保证目标可聚焦且不被固定栏遮挡。

## 性能预算

每个实例一个 span、无 hook、监听、observer 或 timer。高频 live region 更新应由调用方节流，避免辅助技术公告队列堆积。

## 测试证据

- Unit: `VisuallyHidden.test.tsx` 覆盖 SSR 文本/语义、class 合并、不设置 aria-hidden、focusable 属性隔离、focus-reveal class 与 React ref
- Story interaction: `AccessibleIconButton` 验证纯图标按钮由隐藏文本获得可访问名称；仓库门禁 `check-storybook-links` 本地验证 `play-fn 81/81`（81 个 Storybook title 均至少一个有意义 play）。
- Storybook 浏览器矩阵：本地扫描器在 390×844 视口验证 444 个 Story × 7 场景（Light、Dark、en-US、RTL、reduced-motion、200% 字体、forced-colors），共 3,108 个组合；有 play 的 Story 必须先返回 `storyFinished=success`，再运行 axe WCAG A/AA，结果为 0 违规、0 `pageerror`。
- 官网 Next 运行时：本地 production build 在 390×844 下逐页验证 68 个组件页的 Light/Dark（136 场景）；主题恢复、H1/预览/API 结构、React `pageerror` / `console.error`（含 hydration mismatch）和 axe WCAG A/AA 均通过。
- Bundle：Rollup tree-shaken ESM（React 与包 peer dependencies external）单一公开值 gzip 412 B / 32768 B 预算，组合 Brotli 323 B；共享样式由应用单独导入一次。
- SSR/hydration: SSR 单测已覆盖；隔离 Next 16 App Router hydration 后文本保留在可访问树并维持 1×1px absolute clip，0 hydration/runtime error
- RTL: 样式无方向依赖；文案 locale 待集成层验证
- Reduced motion: 不适用，无动画
- Mobile Chromium/WebKit E2E: 基础原语场景在两种引擎断言隐藏文本仍 attached、`position:absolute` 与 1px 宽度，并通过 `aria-labelledby` 命名状态输出
- Chromatic Light/Dark: 已有 AccessibleIconButton Story，更新基线待 CI 发布
- Real device: Windows High Contrast、VoiceOver、TalkBack 待补
