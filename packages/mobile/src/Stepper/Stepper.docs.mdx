# Stepper

## 当前能力

- 文本输入 + 两个原生按钮组成的 spinbutton，支持点击、可选长按重复、触摸、键盘、直接输入、复制粘贴、受控/非受控与 ref。
- min/max/step/precision 统一规范化；反向 bounds 排序、非法 step 回退 1、浮点按 step base 对齐；过粗 precision 会提升到 step/min 所需位数，避免连续步进停滞。
- 支持 `allowEmpty` 的 null、可配置 inputMode、小数点/小数逗号、严格十进制粘贴、无效草稿回滚、IME 保护、可取消的调用方 keydown。
- 原生 form name/required/disabled/readOnly/reset；readOnly 会保留 FormData 并忽略所有内建改值键；Field label、必填、说明和错误关联；增减按钮通过 aria-controls 指向输入。
- Field 与调用方的 `aria-labelledby` / `aria-describedby` 按 token 合并去重；中间有布局 wrapper 时仍保留可访问名称和说明。
- 44px 按钮、三档高度、RTL 逻辑边框、reduced-motion 和 forced-colors 降级。

当前为 V2 `verification`；单元、SSR、Story、本地 axe 与全库移动浏览器门禁已建立，尚缺最终视觉与真机验收，不能标记为 commercial。

## 何时使用

购物数量、人数、份数、重量增量等精确数值，常用值可通过少量点击完成，同时允许键盘直接输入。

## 何时不要使用

- 只需感知相对值时用 Slider；少量枚举值用 Selector；手机号、验证码不是数字运算，使用 TextInput。
- 金额结算、任意精度金融数、科学计数、分数、单位换算不要只依赖 JS number；业务应使用 decimal/string 模型。
- 超大范围、高频连续变化不适合逐步点击。

## 结构与状态

DOM 顺序为 decrement button、text input(role spinbutton)、increment button。状态为 default/focus/error/readOnly/disabled，边界会分别禁用按钮。根暴露 component/size/state data 属性；内部 class 不稳定。

## 基础用法

```tsx
<Field label="购买数量" required description="每人限购 8 件">
  <Stepper name="quantity" min={1} max={8} defaultValue={1} />
</Field>
```

小数：

```tsx
<Stepper name="weight" min={0} max={20} step={0.25} precision={2} defaultValue={1.5} />
```

## 受控与非受控

- value 不为 undefined 时受控；null 是合法空值，不代表非受控。
- 聚焦时建立字符串草稿，允许用户暂时输入 `-`、`.` 等中间形态；blur/Enter 才解析、对齐并调用 onChange。
- 无效草稿或不允许空值的空草稿回滚到当前规范值，不发 change；allowEmpty 时空草稿提交 null。
- 可交互时，按钮/Arrow/Home/End 立即提交；readOnly/disabled 时所有内建改值键保持值不变。Escape 回滚草稿但保留焦点。
- form.reset 返回时原生 DOM/FormData 已同步恢复 defaultValue，随后只同步 React 状态且不调用 onChange；取消 reset 时保持当前值，受控状态由父级决定。

## 数值、精度与边界

- 有限 min/max 转升序；单边 bounds 保留；NaN/Infinity 输入回滚或规范化。
- step 必须正且有限；以有效 min（没有则 0）为基准吸附。max 不在步长网格上时，有效上限为最后一个可达步进值；End、增加按钮、ARIA 上限和发布值统一使用该端点。
- precision 显式且有限时限制 0–12；若小于 step/min 所需位数，组件提升到所需位数，保证每次 step 都可表示并继续前进。省略或传非有限值时取 step/min 的十进制位数。回调是 number，不保留视觉末尾零。
- 草稿只接受带可选正负号的十进制整数或小数；仅含一个逗号且不含点号时，逗号作为 decimal separator。科学计数、十六进制、分组空格、千分位、货币符号和本地化数字字形会回滚。

## 表单集成

- input 透传 name、form、required、disabled、readOnly、onInvalid、autocomplete、paste/composition handlers 等适用属性。`inputMode` 默认 decimal，也可设为 numeric/text 等原生提示；它只选择软键盘，不改变十进制解析规则。
- Field required 会落到原生 text required 与 `aria-required`；空值可被浏览器 validity/RHF 捕获。
- min/max/step 是组件数值契约，不是 text input 的原生 constraint validation；服务端/schema 必须重复验证。
- readOnly 仍进入 FormData且可聚焦/选择；ArrowUp/ArrowDown/Home/End 不修改受控或非受控值，调用方 onKeyDown 仍先执行，Home/End 的原生光标行为不被组件阻止。disabled 不进入 FormData且按钮不可操作。
- ref 指向 text input，可 focus/select、读取 form/validity/value。
- `MeuFormStepper` 在 RHF 校验错误与调用方显式 `status="error"` 间取并集，不会在字段当前有效时清除业务错误视觉。

## Props

完整 API 由 types TSDoc/API Extractor生成。专有 Props：value/defaultValue、min/max/step/precision、allowEmpty、incrementAriaLabel、decrementAriaLabel、size、status、onChange；其余来自原生 input（冲突字段除外）。

## Events

- `onChange(value)`：按钮、键盘步进、长按重复 tick 或有效草稿 commit 后，且规范值确实变化时触发。
- `onFocus/onBlur/onKeyDown` 保留调用方 handler；blur 在内部 commit 后交给调用方。
- 调用方 onKeyDown 先运行；preventDefault 会取消内建处理。IME composing/keyCode 229 不触发步进。
- 原生 onInput/composition/paste 可透传，但自定义 onChange 不是逐字符事件。

## Ref 与命令式方法

ref 指向中央真实 input，可使用原生 `focus()`、`blur()`、`select()`、selection 与 form API。增减按钮没有公开 ref；
程序化步进应更新受控 value，而不是模拟按钮点击。

## 键盘操作

| 按键       | 行为                                |
| ---------- | ----------------------------------- |
| ArrowUp    | 可交互时增加一个 step               |
| ArrowDown  | 可交互时减少一个 step               |
| Home / End | 可交互且有对应边界时提交 min/max    |
| Enter      | blur 并提交草稿                     |
| Escape     | 回滚草稿、保留焦点与当前值          |
| Tab        | 按 DOM 顺序经过减按钮、输入、增按钮 |

## 触摸与手势

按钮最小 44×44 CSS px并使用原生 button 激活语义；`touch-action: manipulation` 与不可选文字避免长按期间出现文本选区。`repeatOnLongPress=false` 保持单击一次一步；启用后，按住 500ms 触发第一步，此后每 100ms 重复，pointerup/pointercancel/lost capture、readOnly/disabled、关闭开关或卸载都会清理计时器。重复开始后抑制尾随 click；取消发生在首次重复前时，只提交输入框已编辑的草稿。组件不处理滑动，也不安装 document 监听；页面滚动与系统手势保持原生。

## 无障碍

- input role=spinbutton 暴露 value now/min/max/required/invalid；有效编辑草稿会同步 value now，不完整或非法草稿不沿用旧值；必须有 Field label 或 ARIA name。嵌套 Field context 与调用方 idref 会合并去重。
- 增减按钮有 ConfigProvider 本地化名称（中：增加/减少，英：Increase/Decrease）和 aria-controls。
- 边界、readOnly/disabled 会禁用相应按钮；错误由 Field describedby + aria-invalid 公布。
- 无 Field/status error 时保留 spinbutton 上显式 `false/grammar/spelling` token；grammar/spelling 触发错误视觉。Field/status error 优先输出 `true`，token 不复制到增减按钮。
- 状态不只靠颜色；按钮 disabled、input readonly/disabled 和 ARIA 提供语义。

## 动效

只有边框/focus 过渡和即时 active 背景；reduced-motion 把过渡缩至 1ms。长按计时控制值变化，不是视觉动画；reduced-motion 不改变其 500/100ms 输入节奏。

## 主题与定制

forced-colors 使用系统 ButtonText/FieldText，焦点由 outline 保留。主题使用
surface/subtle/ink/muted/border/accent/danger。稳定入口为 size、status、按钮 accessible labels 与全局 Token；内部 grid
和 className 不是覆盖 API。

## SSR 与 Next.js

- render 不读取浏览器全局；服务端确定输出两按钮、spinbutton、ARIA、dir、inputMode 和规范值。JSDOM hydrateRoot 已证明相同 RTL 首屏无 recoverable error；effect 只在客户端关联 form reset 与清理长按计时器。

## RTL 与国际化

- dir 同时传给 root/input；grid 顺序随 direction，按钮分隔线使用逻辑边框。数字内容方向可由调用方单独设 dir。

## 浏览器与 WebView

构建产物通过 Chrome 70 / iOS 13 语法基线。inputMode 只提示软键盘，不保证 decimal 键盘包含负号/小数符号；Unit 已验证 paste/composition 事件、十进制逗号与 commit 状态机，但键盘布局、候选栏、selection 和系统级 pointercancel 仍需在目标 WKWebView/Android WebView 真机验证。

## 边界情况与已知限制

- JS number 最多 12 位小数保护，不适合金融 arbitrary precision。
- 没有 formatter/parser、单位前后缀或 wheel 步进；长按重复需显式开启，不做加速。
- 受控 value 被规范化显示；父级若持续传超界值，回调不会自动修正父状态。
- 原生 text validity 不认识 min/max/step；必须有业务/schema 校验。
- decimal comma 只处理简单单逗号，不处理 locale grouping。

## 性能预算

无第三方运行时、layout read、持续 timer 或 document listener；每次 commit 为常数级解析/规范化。form reset 仅在拥有 form 且非受控时安装一个监听器。
