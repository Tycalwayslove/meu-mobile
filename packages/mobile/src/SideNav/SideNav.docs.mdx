# SideNav

## 当前能力

同一 API 支持带 content 的 APG vertical tabs 和无 content 的 navigation rail；受控/非受控、automatic/manual、禁用跳过、roving focus、Home/End、长列表滚动入视、panel 保留/销毁与 badge。

## 何时使用

用于移动端同层级分类或窄侧栏内容切换；带 content 时由组件关联 panel，无 content 时业务持有内容/路由。

## 何时不要使用

一级页面入口用 TabBar，水平少量切换用 Tabs。树形层级和异步子节点使用 TreeSelect；SideNav 不表达嵌套层级。

## 结构与状态

Panels 模式为 `root → tablist → tab buttons + tabpanels`；Navigation 模式为 `root → navigation → buttons`。状态 active/inactive/disabled/focused，长 rail 原生 overflow。

## 基础用法

```tsx
<SideNav aria-label="分类" items={[{ key: "food", label: "食品", content: <Food /> }]} />
```

## 受控与非受控

value 存在（含 null）即受控。无效/禁用受控 key 不选中 item/panel，但首个 enabled item 保留 roving Tab stop。点击会同步 roving key；删除或禁用已聚焦项时，焦点迁移到新的 roving target。非受控 current key 会永久归一，旧 key 重现不会跳回。

## 表单集成

导航不是表单值，button 固定 type=button，不提供 adapter/name/FormData。

## Props

只要任一 item 有 content 即进入 Panels 模式，并为所有 item 建立 panel。destroyInactive 会卸载内部状态。badgeLabel 可替代短 badge 的读屏文本。item.key 必须唯一稳定。

## Events

onChange(key,event) 在点击、automatic 焦点移动或 manual Enter/Space 激活新 key 时触发；受控状态等待调用方。重复激活当前 key 不触发。

## Ref 与命令式方法

ref 指向 root div；不公开路由/切换命令。当前项变化后组件尽力 scrollIntoView nearest；旧 WebView 缺失该方法时静默降级。

## 键盘操作

| 按键                | 行为                                        |
| ------------------- | ------------------------------------------- |
| ArrowDown / ArrowUp | 循环移动并跳过 disabled；automatic 同时激活 |
| Home / End          | 首个/末个 enabled item                      |
| Enter / Space       | manual 模式激活聚焦项                       |
| Tab                 | 经过 rail 单一 roving Tab stop              |

## 触摸与手势

rail item 至少 104×52px；纵向滚动使用原生惯性，不拦截触摸或实现拖拽。

## 无障碍

Panels 模式完整 tablist/tab/tabpanel 双向关联与 aria-selected；Navigation 模式具名 landmark + aria-current=page。disabled 原生禁用，badge 可提供 label。

## 动效

无选择位移动画；reduced-motion 不适用。

## 主题与定制

使用 subtle/surface/ink/muted/accent/danger/border Token；forced-colors 保留 rail item/panel 边界。内部 class 非 API。

## SSR 与 Next.js

useId 保证关联稳定；首屏 items/value 必须一致。组件不导入 Next Router，不内置 Link；Navigation 模式仍是 button，由 onChange 接路由。

## RTL 与国际化

rail 边界和 active 标记使用逻辑 inline 属性，RTL 时 rail 自动位于起始侧。上下键不镜像；默认名称支持中英文。

## 浏览器与 WebView

原生 overflow + WebkitOverflowScrolling 面向移动 WebView；scrollIntoView 缺失时焦点/选择仍正确。逻辑属性老内核仅可能视觉降级。

## 边界情况与已知限制

调用方必须给 root 明确高度才能形成内部滚动。混合 content 会给无 content item 建立空 panel。组件不支持 nested items、sticky 页面定位或异步 loading 状态。

## 性能预算

rail O(items)；默认 panels 也 O(items)，destroyInactive 降低 DOM 但丢失局部状态。数百项应改用搜索/树或虚拟化方案。
