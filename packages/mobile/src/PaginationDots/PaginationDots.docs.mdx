# PaginationDots

## 当前能力

默认是只读页位摘要；显式 `interactive` 后才渲染原生页码按钮。支持 dot/line、横竖、RTL、超多页压缩和本地化名称。

## 何时使用

用于 Carousel、引导页或分页内容的位置反馈；可操作模式仅用于确实允许随机跳页的场景。

## 何时不要使用

需要上一页/下一页、页码输入或服务端分页时使用完整 Pagination。不要让只读 marker 看起来可点击。

## 结构与状态

只读为 `div[role=img] → marker`；交互为 `div[role=group] → button + ellipsis`。状态包含 current、idle 与 compressed。

## 基础用法

```tsx
<PaginationDots count={12} activeIndex={page} interactive onChange={setPage} />
```

## 受控与非受控

只接受受控 `activeIndex`；组件不猜测 Carousel 状态。索引越界会静默夹紧，非有限索引归零，`count` 非法时归零。

## 表单集成

不适用：分页位置不是表单字段，按钮固定 `type="button"`。

## Props

`maxVisible` 归一到 5–99、默认 7；超大 count 归一到安全整数上限，所有渲染路径都保持固定 DOM 上限。`getPageLabel(index,count)` 只覆盖交互按钮名称。

## Events

`onChange(index,event)` 仅在 interactive 且点击非当前页时触发；状态仍由调用方更新。

## Ref 与命令式方法

ref 指向根 `HTMLDivElement`；无命令式翻页 API。

## 键盘操作

| 按键            | 行为                                  |
| --------------- | ------------------------------------- |
| Tab / Shift+Tab | 仅 interactive 模式逐个进入可见页按钮 |
| Enter / Space   | 激活聚焦页按钮                        |

## 触摸与手势

交互按钮为 44×44 CSS px；组件不处理滑动手势。

## 无障碍

只读模式提供“当前页/总页数”单一摘要。交互按钮提供完整页码名称，当前项使用 `aria-current="page"`；ellipsis 隐藏于读屏。

## 动效

marker 尺寸和颜色过渡使用 motion token；reduced-motion 缩短到 1ms。

## 主题与定制

颜色使用 accent/muted token；forced-colors 使用系统颜色。稳定入口为 props 与 data 属性。

## SSR 与 Next.js

纯确定性标记；不访问浏览器全局。服务端与客户端需提供一致 count/index。

## RTL 与国际化

flex 自动遵循继承方向；页码逻辑仍为零基索引。默认中文/英文名称可由 aria-label/getPageLabel 覆盖。

## 浏览器与 WebView

仅使用原生 button、flex 与基础 CSS，兼容 Chrome/WebView 70+、iOS 13+；无 ResizeObserver 依赖。

## 边界情况与已知限制

压缩后只渲染首尾、当前邻近页和省略号；不可见页仍可通过业务的前后翻页入口抵达。重复业务页身份不由组件处理。

## 性能预算

DOM 数量压缩为 O(maxVisible)，不随巨大 count 线性增长。
