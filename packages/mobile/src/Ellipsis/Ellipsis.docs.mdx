# Ellipsis

## 当前能力

按真实容器内容宽度对纯文本进行 start/end/middle、单行或多行截断；支持受控/非受控展开、可隐藏或自定义操作内容、React 19 cleanup ref、操作按钮 ref 与独立无障碍名称。测量响应自身 class/style、显式 `remeasureKey`、ResizeObserver、viewport/orientation resize、字体 ready 和后续字体加载；SSR 首帧使用原生 clamp，完整文本始终供读屏获取。

## 何时使用

用于卡片摘要、说明和长标识符的视觉压缩，且用户可选展开查看完整内容。

## 何时不要使用

法律文本、错误原因、主要操作说明不能默认隐藏。富文本、链接混排或需要保留 DOM 标记时不要使用，因为 content 仅接受 string。

## 结构与状态

`root → visually-hidden full text + aria-hidden visual text + action? + hidden measurement mirror`。状态 pending、complete、collapsed、expanded。

## 基础用法

```tsx
<Ellipsis content={description} rows={2} direction="end" />
```

## 受控与非受控

expanded 存在即受控；否则 defaultExpanded 初始化。测量状态按 content/direction/rows 身份隔离，prop 更新等待新测量时显示当前完整内容的 CSS clamp，不闪回旧文本。

## 表单集成

不提交值；展开按钮固定 type=button，可安全放入 form。

## Props

| Prop                | 类型                                                                    | 默认值   | 说明                                                         |
| ------------------- | ----------------------------------------------------------------------- | -------- | ------------------------------------------------------------ |
| `content`           | `string`                                                                | 必填     | 完整纯文本；视觉截断不修改该来源                             |
| `rows`              | `number`                                                                | `1`      | 收起时最大行数；有限值向下取整并限制为至少 1，非有限值回退 1 |
| `direction`         | `"start" \| "middle" \| "end"`                                          | `"end"`  | 保留字符数组的起点、两端或终点；不改变 DOM `dir`             |
| `expanded`          | `boolean`                                                               | -        | 受控展开状态                                                 |
| `defaultExpanded`   | `boolean`                                                               | `false`  | 非受控初始展开状态，只在首次挂载读取                         |
| `expandText`        | `ReactNode`                                                             | `"展开"` | 展开操作可见内容；falsy 时隐藏收起态操作                     |
| `collapseText`      | `ReactNode`                                                             | `"收起"` | 收起操作可见内容；falsy 时隐藏展开态操作                     |
| `expandAriaLabel`   | `string`                                                                | -        | 展开按钮无障碍名称覆盖，适用于图标或含糊文案                 |
| `collapseAriaLabel` | `string`                                                                | -        | 收起按钮无障碍名称覆盖                                       |
| `onExpandedChange`  | `(next, event: MouseEvent<HTMLButtonElement>) => void`                  | -        | 原生 button 激活计算下一状态后调用                           |
| `onEllipsisChange`  | `(ellipsed: boolean) => void`                                           | -        | 完成测量且“是否需要截断”的布尔值改变时调用                   |
| `ref`               | `Ref<HTMLDivElement>`                                                   | -        | 根 div ref                                                   |
| `actionRef`         | `Ref<HTMLButtonElement>`                                                | -        | 当前操作按钮 ref；无需操作或对应文案为 falsy 时为 null       |
| `remeasureKey`      | `string \| number`                                                      | -        | 祖先排版改变但容器未 resize 时，改变该值强制重新测量         |
| 原生 `div` 属性     | `HTMLAttributes<HTMLDivElement>`（除 children/dangerouslySetInnerHTML） | -        | `id`、`dir`、ARIA、data、className、style 和根事件透传       |

`direction` 只控制保留文本片段，不改变文档方向。生成的 class 名、测量镜像和候选文本不是公共 API；稳定观测入口为 `data-meu-component`、`data-direction`、`data-state` 与 `data-meu-ellipsis-action`。

`expandText` / `collapseText` 仅接受简短文本或装饰图标；不得放 button、link、input、带全局唯一 id 的节点或有副作用的组件。`expandText` 会同时出现在隐藏测量镜像与真实 action 中，复杂内容既可能产生重复 DOM identity，也会让宽度测量失真。

## Events

`onExpandedChange(next,event)` 由点击、Enter 或 Space 产生的原生 button 激活触发；受控状态不乐观改变，事件不可由 Ellipsis 取消。内容/行数/方向变化进入 pending 时保留上一轮操作按钮，避免仍需截断的重测过程卸载焦点。`onEllipsisChange` 仅在完成测量且布尔结果变化时触发；同一结果的重复 resize/font 通知不会重复回调。

## Ref 与命令式方法

`ref` 指向根 div；`actionRef` 指向当前可见的原生 button。React 19 callback ref 返回的 cleanup 会原样执行；旧式 callback ref 在节点消失或卸载时仍收到 null。容器 resize、组件自身 `className`/`style`、viewport/orientation change、字体 ready 与后续 `loadingdone` 会自动触发；祖先 class、CSS 变量或媒体查询只改变排版但没有造成尺寸通知时，调用方应改变 `remeasureKey`。业务不应读写隐藏测量节点。

## 键盘操作

| 按键          | 行为                  |
| ------------- | --------------------- |
| Tab           | 聚焦可见展开/收起按钮 |
| Enter / Space | 原生切换展开状态      |

## 触摸与手势

操作按钮至少 44×44px，不拦截滚动、长按选择或复制。

## 无障碍

完整文本通过 VisuallyHidden 暴露一次，视觉候选 `aria-hidden`，避免读出省略号或重复。按钮使用 `aria-expanded`；可见文案通常形成 accessible name，图标或含糊文案必须同时提供 `expandAriaLabel` / `collapseAriaLabel`。本地化内容与按钮名称由调用方负责。

## 动效

无展开动画，状态立即替换，因此 reduced-motion 不适用。

## 主题与定制

按钮使用 accent Token；forced-colors 使用 LinkText/ButtonText。字体、line-height 与颜色继承容器；内部测量 class 非 API。

## SSR 与 Next.js

服务端输出完整 accessible text 与完整视觉文本的 CSS line-clamp fallback，不输出未经测量的按钮。hydration 初始结构一致，client effect 后再精确候选。

## RTL 与国际化

逻辑 margin/padding 支持 RTL；start/end 是文本数组的起止，不自动按 bidi 视觉顺序重排。复杂混合方向内容应先由业务确认显示策略。

## 浏览器与 WebView

正式支持矩阵为 iOS Safari/WKWebView 15+ 与 Android Chrome/WebView 89+。优先使用 ResizeObserver；缺失时监听 window resize，同时始终监听 orientationchange。FontFaceSet 可用时在 ready 和后续 loadingdone 重测；缺失不影响初始与 resize 测量。requestAnimationFrame 缺失时退化到零延迟 timer。完整支持档使用 `Intl.Segmenter` 按 Unicode grapheme 切分。

旧内核无 `Intl.Segmenter` 时的轻量 fallback 只保证常见 ZWJ emoji、旗帜、肤色、variation selector 与部分组合附加符；它不是完整 UAX #29 实现，不承诺 Indic spacing mark/virama、Hangul Jamo 或 CRLF 的完整 grapheme 聚合。iOS 13–14 与 Chromium 70–88 属于观察档或静态语法扫描档，不构成完整运行时承诺；业务若必须支持这些内核，应避免依赖视觉候选的精确字符边界并完成专项真机验收。

## 边界情况与已知限制

宽度为 0 或镜像无法得到有效单行高度时保持 pending，直到后续 resize/font 通知。可用宽度会扣除根元素左右 padding；单行高度从同字体的镜像直接测得，不猜测 `line-height: normal`。全选复制可能包含辅助隐藏文本与视觉文本，单独复制建议从业务原始 content 提供复制按钮。

容器窄于 44px 操作按钮最小触控宽度，或“省略号 + action”本身无法放入允许行数时，操作可能额外占一行；此时应增加容器宽度、隐藏 `expandText` 使用纯截断，或在组件外提供查看全文操作。组件不会为了满足行数而把触控目标缩小到不可用。

若祖先 class、主题变量或媒体查询改变 font/letter-spacing，但根元素边框盒尺寸不变且浏览器不触发字体事件，ResizeObserver 不会产生通知。调用方应把对应排版版本传给 `remeasureKey`；组件自身 `className`/`style` 变化则会自动重测。

## 性能预算

每次测量使用 O(log n) 次布局读取，每实例一个 ResizeObserver；大列表中应限制实例数量或预先截断非关键文本。

## 未来变更规则

- 保持 `content: string`、默认 `rows=1`、默认 `direction=end`、中文默认操作文案和现有受控判定不变；任何默认值或事件时序变化都必须作为显式破坏性提案。
- 新增方向、标记样式或富文本能力前，必须先定义 grapheme、bidi、辅助文本、复制和测量契约；不得让视觉候选成为唯一可访问内容。
- 调整按钮 spacing、font 或最小触控面积时，隐藏镜像必须复用同一 action 样式，并新增窄宽度回归测试。
- 调整测量调度时，必须保留 ResizeObserver 缺失、RAF 缺失、字体后加载、宽度为 0、卸载清理和 hydration 无错误证据。
- 公共稳定入口仅限导出类型/Props/Events/ref 和文档声明的 data 属性；不得承诺生成 class、内部 DOM 顺序或二分候选文本的精确字符数。
- 发布前新增 API 必须同步 types、Unit、SSR/hydration（适用时）、Story、README 与本文件，并记录兼容/迁移说明；不得用未执行的矩阵更新“已通过”证据。
