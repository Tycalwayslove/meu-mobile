# ImageViewer

## 当前能力

Portal 全屏模态画廊，支持受控/非受控 open 与 index、scroll lock、focus trap/restore、计数、空/失败、footer、前后切换、pinch/双击/按钮/键盘缩放和放大后平移。所有关键手势都有按钮或键盘等价路径。

## 何时使用

查看商品、评价和凭证大图；单图与有限画廊共用同一组件。

## 何时不要使用

内嵌缩略图使用 Image；视频、PDF、编辑裁剪和无限媒体流不属于此组件。

## 结构与状态

Portal config boundary → Mask → dialog → close/counter → Carousel → figure/ZoomableImage/figcaption → zoom controls。状态包括 open/closed presence、active item request identity、index、scale、loading/error/empty、full/minimal controls。

## 基础用法

```tsx
<ImageViewer
  open={open}
  images={images}
  index={index}
  onIndexChange={setIndex}
  onOpenChange={setOpen}
/>
```

## 受控与非受控

open 使用 `open/defaultOpen/onOpenChange`；index 使用 `index/defaultIndex/onIndexChange`。受控调用方不提交回调值时保持权威输入。越界、NaN 和 Infinity 会归一到有效索引；空数组为 0。

## 表单集成

不适用。Viewer 不修改字段值；Uploader/Form adapter 只在外层持有成功图片数组。

## Props

API 由 `ImageViewerProps` 生成。maxZoom 最小 1、非有限回退 3；doubleTapZoom 被限制在 1..maxZoom。每个 item 必须提供 src 与 alt；装饰图也应考虑画廊是否仍有可理解名称。当前项的 index、key 或完整请求参数（src/srcSet/sizes/CORS/referrer policy）变化时会原子重置 transform 与外层 scale，A → B → A 不恢复旧资源的缩放。

## Events

`onOpenChange(open,{reason})` 区分 close-button/escape；`onIndexChange(index,{reason})` 区分 drag/previous/next/imperative；`onScaleChange(scale,{index,reason})` 区分 double-tap/pinch/reset/zoom-in/zoom-out。只有实际变化才发布 index/scale。

## Ref 与命令式方法

`goTo/previous/next/resetZoom/nativeElement`。命令式导航仍经过 loop/clamp，并以 imperative reason 发布。

## 键盘操作

| 按键                   | 行为                           |
| ---------------------- | ------------------------------ |
| Escape                 | closeOnEscape 时请求关闭       |
| ArrowLeft / ArrowRight | 按 LTR/RTL 视觉方向切换        |
| + / = / -              | 放大 / 缩小                    |
| 0                      | 重置缩放                       |
| Tab / Shift+Tab        | 在模态内循环，关闭后恢复触发器 |

## 触摸与手势

双指缩放、双击切换缩放、放大后单指/鼠标平移；scale>1 时暂停 Carousel 横向拖动。鼠标 pointer up/cancel、lost pointer capture 与窗口失焦都会清理平移；无法取得 pointer capture 时不启动鼠标平移，按钮与键盘缩放继续可用。touch cancel 不参与双击判定。控制按钮均为 44×44。实际 iOS 边缘返回、页面滚动和多指取消仍需真机验证。

## 无障碍

根为命名 `aria-modal` dialog，打开时锁滚动并圈定/恢复焦点。图片使用 item.alt；计数器 polite/atomic。`renderFooter` 是当前图片 figure 的 figcaption。最终图片错误会重置为 1×、恢复 Carousel drag，并用“alt + 加载失败”的独立 polite status 宣告；空和错误状态保留关闭操作。minimal 只隐藏画廊与缩放控制，不隐藏关闭按钮。

## 动效

layer opacity 和 transform 使用 Meu motion。Portal 根复制 ConfigProvider 的 motion class 与 `data-meu-motion`；显式 reduced 为 0ms，系统 `prefers-reduced-motion` 为 0–1ms。手势交互中 transition 为 0，松手后立即 clamp。

## 主题与定制

Mask、surface、ink、border、shadow 与 focus 来自 Token；Portal 根同步 locale、dir、theme 与 motion。稳定入口为 controls、labels、renderFooter、container 和 data 属性，内部 Carousel/ZoomableImage class 非 API。

## SSR 与 Next.js

关闭态服务端输出空字符串；打开态 Portal 在服务端按 primitive 契约降级，生产中建议 open 初值与客户端一致。图片数组 key/order 必须 hydration 稳定。

## RTL 与国际化

ConfigProvider 提供中英文文案与 dir。控制位置使用逻辑属性；键盘左右方向在 RTL 中翻转，Carousel 自身负责轨道方向。

## 浏览器与 WebView

依赖 Portal、focus trap、Pointer/Touch、pointer capture、CSS transform 与 visual viewport 宿主行为。完整运行时支持档为 Android Chrome/WebView 89+ 与 iOS Safari/WKWebView 15+；iOS 13–14、Chromium/WebView 79–88 属观察档，Chrome 70 仅为构建产物旧语法扫描，它们都不构成完整支持承诺。系统缩放、地址栏、刘海安全区和真机多指手势仍需发布验收。

## 边界情况与已知限制

- 不支持旋转、下载、分享、版权鉴权或视频。
- 平移边界按 stage 尺寸近似，不读取图片自然宽高。
- footer 内容过长会在受限宽度内换行；交互 footer 需自行验证焦点顺序。
- 受控导航请求只有在权威 index 实际改变后才重置缩放；owner 拒绝请求时保留当前图片与缩放。外部直接改变 index 时，调用方应同步业务 footer 状态。
- 图片最终错误会发布一次 `reset` scale reason（仅在错误前 scale 实际大于 1 时）；Viewer item 当前没有 fallbackSrc，因此原生 error 即最终错误。

## 性能预算

当前 Carousel 会渲染全部 item；建议有限集合和响应式图片。超大画廊应在应用层分页，不把原图全量预载。
