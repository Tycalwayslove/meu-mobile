# Image

## 当前能力

Image 是保留原生 `img` 语义的状态型图片原语：

- `loading → loaded → error` 三态、加载 placeholder、最终 fallback，以及一次 primary → `fallbackSrc` 来源回退。
- 原生 `alt`、`src/srcSet/sizes`、`loading`、`decoding`、`fetchPriority`、CORS、referrer policy、拖拽和受约束的 `imageProps`。
- `fit`/`position` 裁切、`aspectRatio` 比例预留、数字或 CSS 字符串宽高、四种圆角。
- 空源、失败、缓存完成、SSR 与 hydration 的确定性行为；不自行 fetch、缓存、重试或推导 CDN URL。

状态仍为 `verification`：仓库自动化已覆盖核心语义，真实 iOS/Android、VoiceOver/TalkBack、旧 WebView 弱网和最终视觉基线仍按发布签字表执行。

## 何时使用

用于商品图、内容图、卡片媒体和需要稳定占位、响应式候选或错误回退的图片。装饰图片必须显式传 `alt=""`。

## 何时不要使用

- 人物或店铺头像使用 Avatar。
- 全屏缩放、手势浏览使用 ImageViewer。
- Next.js 图片优化、CDN loader、预加载和 blur data URL 由应用层的 `next/image` 或媒体服务负责。
- 需要 `<picture>`/`source media`/格式协商时，由业务渲染原生 `<picture>`；Image 当前只封装单个 `img`。

## 结构与状态

```text
root[data-state][data-source]
├─ loading: placeholder overlay + native img
├─ loaded: native img
└─ error: accessible fallback（native img 卸载）
```

`data-state` 为 `loading | loaded | error`，`data-source` 为 `primary | fallback`，root 固定公开 `data-meu-component="image"`。有 primary 时先请求 `src/srcSet`；其原生 error 事件触发后，有效 `fallbackSrc` 会作为单一 `src` 请求，并移除 primary `srcSet`。第二次失败才进入最终 error。primary 缺失但 `fallbackSrc` 有效时，SSR 首帧直接从 fallback source 开始。

## 基础用法

```tsx
<Image
  src={product.src}
  srcSet={`${product.small} 480w, ${product.large} 960w`}
  sizes="(max-width: 480px) 100vw, 480px"
  alt={product.name}
  width="100%"
  aspectRatio="16 / 9"
  intrinsicWidth={960}
  intrinsicHeight={540}
  loading="lazy"
/>
```

## 比例裁切与来源回退

```tsx
<Image
  src={product.cdnUrl}
  fallbackSrc={product.originalUrl}
  alt={product.name}
  width="100%"
  aspectRatio="4 / 3"
  fit="cover"
  position="70% center"
  placeholder="图片加载中…"
  fallback="暂时无法显示图片"
/>
```

## 受控与非受控

不适用。`src`、`srcSet` 和 `fallbackSrc` 是调用方事实源；任一来源变化都会同步派生为新周期的首帧 `loading`/`error`。内部只记录当前来源周期和 primary/fallback 阶段，不缓存历史成功或失败。

## 表单集成

不适用。Image 不参与 FormData、dirty 或 validation，也不创建交互控件。

## Props

| Prop                                           | 类型                                  | 默认值          | 契约                                                                              |
| ---------------------------------------------- | ------------------------------------- | --------------- | --------------------------------------------------------------------------------- |
| `alt`                                          | `string`                              | 必填            | 原生替代文本；装饰图片传空字符串                                                  |
| `src`                                          | `string`                              | —               | primary URL；空白字符串视为缺失                                                   |
| `srcSet`                                       | `string`                              | —               | 原生响应式候选；可在无 `src` 时独立提供 primary                                   |
| `sizes`                                        | `string`                              | —               | 与 primary `srcSet` 配套的原生尺寸提示                                            |
| `fallbackSrc`                                  | `string`                              | —               | primary 失败后最多请求一次的备用 URL；primary 缺失时直接使用                      |
| `placeholder`                                  | `ReactNode`                           | 默认图片 glyph  | loading 覆盖层；不得包含交互控件                                                  |
| `fallback`                                     | `ReactNode`                           | 默认图片 glyph  | 最终 error 视觉；不得包含交互控件或另一套图片语义                                 |
| `loading`                                      | `"eager" \| "lazy"`                   | `"eager"`       | 原生加载策略，不内建 IntersectionObserver                                         |
| `decoding`                                     | 原生值                                | `"async"`       | 浏览器解码提示                                                                    |
| `fetchPriority`                                | 原生值                                | —               | 请求优先级提示；只给真正的 LCP 图片使用 `high`                                    |
| `crossOrigin` / `referrerPolicy` / `draggable` | 原生值                                | — / — / `false` | 直接传给每次底层 `img` 请求                                                       |
| `width` / `height`                             | `number \| string`                    | —               | root CSS 尺寸；正数 number 对会自动形成可收缩比例盒，并作为默认原生尺寸           |
| `intrinsicWidth` / `intrinsicHeight`           | `number`                              | —               | 单独覆盖 native img 固有尺寸，推荐与响应式 root 尺寸配合                          |
| `aspectRatio`                                  | CSS `aspect-ratio`                    | —               | 在字节到达前预留比例；配合响应式宽度降低 CLS                                      |
| `fit`                                          | CSS `object-fit`                      | `"cover"`       | 图片适配方式                                                                      |
| `position`                                     | CSS `object-position`                 | `"50% 50%"`     | 裁切焦点                                                                          |
| `radius`                                       | `none \| control \| surface \| round` | `none`          | root 与图片裁切圆角                                                               |
| `imageProps`                                   | `ImageNativeProps`                    | —               | 底层 img 的非冲突原生属性；`className/style` 合并，Image 的 fit/position 最终生效 |
| `ref` / `imageRef`                             | React ref                             | —               | 分别指向稳定 root 和当前 native img                                               |
| 其余 root props                                | `HTMLAttributes<HTMLDivElement>`      | —               | 传给 wrapper；不包含 children/onLoad/onError                                      |

`width/height` 的 `NaN`、Infinity 和负 number 归零，保证 SSR 不输出非法数值。两者均为正 number 时，root 使用宽度加推导比例，不保留会在 `max-width:100%` 下失真的固定高度；原生 width/height 仍默认接收这组数值。`intrinsicWidth/intrinsicHeight` 可覆盖原生尺寸，使布局尺寸与资源比例彻底解耦。CSS 字符串由浏览器校验，`style.width/height/aspectRatio` 仅在对应专有 prop 未提供时生效。

## Events

| Event            | 时机                    | 说明                                                          |
| ---------------- | ----------------------- | ------------------------------------------------------------- |
| `onLoad(event)`  | React 收到 native load  | 状态先在同一批更新为 loaded；fallback source 的事件同样透传   |
| `onError(event)` | React 收到 native error | primary 失败切换 `fallbackSrc`；fallback 再失败进入最终 error |

事件不可取消，也不会为 hydration 前已经完成的缓存请求合成 SyntheticEvent。没有 `onStateChange` 或命令式 retry；业务重试应改变 `src/srcSet/fallbackSrc`，使来源 key 进入新周期。

## Ref 与命令式方法

`ref` 始终指向 root div。`imageRef` 在 loading/loaded 时指向当前 img；无可请求来源或最终 error 时为 null。React 19 callback ref 返回的 cleanup 会原样执行；旧式 callback/object ref 在节点消失或卸载时仍收到 null。primary 切到 fallback 时复用同一个 DOM img，来源属性更新；不保证该节点在未来版本永远复用。无命令式方法。

## 触摸与手势

不拦截触摸或滚动。状态层的最小可见尺寸不是触控目标。不要直接给 Image 添加 click 后假装按钮；将它放入语义正确的 Button/Link。

## 无障碍

- loading/loaded 由原生 img 和必填 `alt` 提供图片语义；root 在 loading 时设置 `aria-busy`，但不创建 live region，避免图片列表批量播报。
- 最终 error 会卸载损坏 img；非空 alt 由 root 以 `role="img"` 和相同 `aria-label` 保留语义，空 alt 则整层 `aria-hidden`。
- placeholder/fallback 是视觉槽位，不应放按钮、链接、另一张带 alt 的 img 或 live region；需要重试按钮时在 Image 外部组合。
- `imageProps` 可传 `aria-describedby`、`title` 和 `data-*` 等 native img 属性；类型与运行时都会阻止它覆盖 alt、aria-hidden、aria-label、aria-labelledby、role、source/request/event 字段。
- alt 应描述图片承载的信息，不写“图片/照片”；邻近文字已完整表达且图片纯装饰时使用 `alt=""`。

## 动效

loading → loaded 仅使用 opacity 淡入；`prefers-reduced-motion` 或 `ConfigProvider motion="reduced"` 下关闭过渡。error 与来源回退无循环动画。

## 主题与定制

背景、文字、圆角和动效来自 Meu Token；forced-colors 增加系统色边界。稳定定制入口为 `radius`、`fit`、`position`、`className/style`、`imageProps.className/style`、placeholder/fallback 以及公开 data 属性。内部 class 名不是契约。

## SSR 与 Next.js

- 首屏 render 不读取 `window`、网络状态或图片缓存；服务端与客户端都由同一 props 计算 primary/fallback、loading/error 和原生属性。
- 有来源时 SSR 输出 placeholder + img；无来源时直接输出可访问 fallback。`fallbackSrc` 在 primary 缺失时会直接进入 SSR img，在 primary 失败时只由客户端原生 error 事件切换。
- hydration 后 effect 才检查 `img.complete/naturalWidth`，用于浏览器缓存已完成但 React 未收到 load/error 事件的情况；它只恢复状态，不伪造已经错过的事件，也不会改变服务器首帧结构。
- Image 不是 `next/image` 替代品，不提供 loader、preload、静态 import 尺寸推导、服务端裁图或 blur data URL。一个页面的 LCP 图片通常使用应用层优化组件，其余内容图片可使用 Image。

## RTL 与国际化

布局与来源状态无方向性；`object-position` 是调用方 CSS 值，如需随 RTL 翻转焦点须由业务选择对应值。alt、placeholder 和 fallback 文案由调用方本地化。

## 浏览器与 WebView

完整支持范围继承 V2 支持矩阵：iOS Safari/WKWebView 15+、Android Chrome/WebView 89+；更早版本为观察档。实现依赖标准 img、`object-fit/object-position`、CSS Grid、`aspect-ratio` 和 requestAnimationFrame：

- 不支持 native lazy loading 的 WebView 会按浏览器规则退化为 eager，请求与无障碍语义仍成立。
- 不支持 CSS `aspect-ratio` 的观察档浏览器仍可从 native `intrinsicWidth/intrinsicHeight` 获得资源比例，但 wrapper 的预留高度可能降级；正式支持档内使用响应式 width + aspectRatio。
- `fetchPriority` 不被识别时只是提示失效，不影响请求。
- 静态旧语法检查不是旧 WebView 完整运行时承诺，真机/宿主验收以发布签字表为准。

## 边界情况与已知限制

- 只有 CSS 字符串宽度且没有 height/aspectRatio 时，未知图片尺寸仍可能产生 CLS。
- `fallbackSrc` 只有一层，不递归、不退避；React 观察到的每个原生失败事件都会触发 `onError`，hydration 前已经结束的缓存请求不会补发事件。
- fallback source 是单一 src，不复用 primary `srcSet`，避免错误候选再次胜出；若备用也需要响应式候选，请由业务换一组 props 开启新周期。
- 浏览器决定候选选择、缓存、解码与错误事件时序；组件不探测网络、不取消下载。
- `imageProps.style.objectFit/objectPosition` 会被顶层 `fit/position` 覆盖，其他样式合并。
- `<picture>`、art direction、自动格式协商、占位色提取和可点击重试不在当前范围。

## 性能预算

常数 DOM、一个 effect、零 Observer/网络包装器。加载态最多 root + state layer + img，loaded 只剩 root + img。实际图片字节、候选数量、CDN 裁剪、缓存和解码成本由调用方负责；长列表使用 `loading="lazy"`，首屏 LCP 不应滥用 lazy。

## 未来变更规则

1. `alt` 必填、native img 语义、root/image 双 ref、`data-state` 三态和现有默认值属于兼容契约；不得在 minor 版本静默改变。
2. 新增来源阶段必须保持有限、确定且 SSR 首帧可推导；不得引入无限自动重试、隐式 fetch、随机 key 或 hydration 前浏览器分支。
3. 新增 native img 属性优先通过明确顶层 prop 或 `ImageNativeProps` 开放；任何冲突字段都必须规定覆盖顺序并增加类型、unit、SSR/hydration 测试。
4. 修改错误/回退语义时必须验证 informative/decorative alt、React 已观察事件次数、缓存恢复、imageRef 清理和 source key 回环重置，并提供迁移说明。
5. 新增视觉状态必须使用 Token，覆盖 Light/Dark、forced-colors、reduced-motion、200% 字体和 320–430px 移动视口；不得把交互职责塞入 placeholder/fallback。
6. 扩大浏览器、Next 或 WebView 支持声明前，必须先完成对应独立消费者和真实设备证据；模拟器、Playwright 与静态扫描不得冒充真机签字。
7. README 与本文件是永久契约，不得在功能合并后降级为临时 TODO；测试证据必须区分“已执行”和“待执行”。
