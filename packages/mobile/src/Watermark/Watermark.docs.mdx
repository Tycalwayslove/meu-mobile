# Watermark

## 当前能力

同构 SVG 交错平铺，支持文本/多行/图片优先与失败回退、单次图片 load/error 事件、字体/尺寸/间距/偏移/旋转/透明度/zIndex，以及可关闭的弱篡改恢复。overlay 不阻止真实内容交互，也不进入无障碍树。

## 何时使用

版权提示、内部资料标识和泄露追踪；水印内容应包含最小必要、经脱敏的来源信息。

## 何时不要使用

不能用于鉴权、加密、防截图、防录屏、防 OCR 或法律意义上的 DRM。敏感内容仍依赖服务端访问控制和审计。

## 结构与状态

relative root → children → absolute aria-hidden SVG/defs/pattern/rect。状态为 text/multiline/image/image-fallback 与 tamper protection on/off；无交互、loading、disabled。

## 基础用法

```tsx
<Watermark content={["Meu Mobile", operatorId]}>
  <Receipt />
</Watermark>
```

## 受控与非受控

不适用。全部视觉输入由 props 派生；图片失败仅对当前 image URL 记录，URL 变化后重新尝试。

## 表单集成

不适用。children 中的表单保持原语义，overlay pointer-events none。

## Props

API 由 `WatermarkProps` 生成。正尺寸限制 1..2048；gap 为 0..2048；非有限值回退默认值；opacity clamp 到 0..1；content 的换行会拆为多行。image 存在时优先于 content。

## Events

平铺内有三枚同源 `<image>`；`onImageLoad` / `onImageError` 对当前 URL 的一次尝试合计最多触发一次，以首先收到的终态事件为准，error 后回退文本，URL 变化后重置尝试。若需要重试完全相同的 URL，应更换 cache-buster 或重新挂载。`onRemove` 只在 overlay 删除或自身属性/文本/子树被篡改并恢复时触发。业务 children 的正常增删不会触发。

## Ref 与命令式方法

`ref` 指向 root div；支持 React 19 callback ref cleanup；无命令式方法。

## 键盘操作

| 按键   | 行为                                        |
| ------ | ------------------------------------------- |
| 不适用 | overlay 不可聚焦，children 保持自身键盘行为 |

## 触摸与手势

overlay 固定 `pointer-events:none`，不截获点击、长按、滚动或手势。

## 无障碍

SVG 为 `aria-hidden=true`、`focusable=false`；水印文字不会被读屏重复播报。根的 aria 属性透传，真实内容语义完全由 children 提供。

## 动效

无动画，reduced-motion 不适用。

## 主题与定制

默认字体、颜色来自 Meu Token；font/color、opacity 和 geometry 可显式覆盖。forced-colors 下 overlay 仍是装饰信息，不作为状态唯一表达。无动画，因此 reduced-motion 不改变输出。稳定入口为 props、root className/style 与 data 属性。

## SSR 与 Next.js

useId 生成稳定 pattern id；render 不读取 window/document。MutationObserver 仅在客户端 layout effect 启动，服务端和客户端首屏 SVG 一致。图片状态只在 effect/event 中变化，不会改变 SSR 首屏结构。

## RTL 与国际化

平铺无方向性；文本不自动翻译或双向隔离。混合 bidi、用户 ID 与本地化日期应由调用方预先格式化，必要时使用 Unicode isolate。

## 浏览器与 WebView

正式支持矩阵为 Android Chrome/WebView 89+、iOS Safari/WKWebView 15+。Chrome 70 / iOS 13 只是 production 构建语法与选择器静态基线，不是完整运行时承诺；iOS 13–14 与 Chromium/WebView 79–88 属观察档。实现依赖 SVG pattern/image、CSS custom properties 和可选 MutationObserver；定位使用 `top/right/bottom/left` 而非旧内核不支持的 `inset`。无 MutationObserver 时仅失去弱篡改恢复，水印仍显示。`href` 与兼容 `xlink:href` 同时输出。

容器尺寸变化由百分比 SVG viewport 原生跟随，不做 JS 几何测量，因此没有 ResizeObserver 依赖或 fallback，也没有 observer resize 竞态。SVG 文字和矢量图片不需要 DPR canvas 重绘；位图应提供至少 2x 源。旧内核运行时、CORS 图片、打印分页仍需目标宿主复验。

## 边界情况与已知限制

- DOM 篡改者可关闭 JS、隐藏祖先、覆盖 CSS 或截图后编辑，tamperProtection 不构成安全承诺。
- 极长文本不自动省略，可能超出 mark box；调用方应提供短标识。
- wrapper 的 `overflow:hidden` 与 Figma `clipsContent=true` 一致，100% SVG viewport 自身也 `overflow:hidden`，业务 children 与水印图案均裁在 host 边界；需要阴影、sticky 或越界提示的内容应调整 DOM 层级，不应依赖越过 Watermark root。
- SVG 前景元素带 print color adjustment 提示，但打印/导出 PDF 的跨页重复、系统省墨、canvas/html2canvas 截图和跨域图片需要业务链路单独验证。
- 组件不创建/revoke object URL；调用方创建的 blob URL 仍由调用方在不再使用后释放。任意外链 URL 可能产生网络请求，敏感查询参数和第三方追踪源不得作为水印资源。

## 性能预算

固定三枚 mark 定义并由 SVG pattern 平铺，DOM 不随容器面积、DPR 或 resize 次数增长。图片事件用 ref 去重，不为三枚 mark 重复提交状态。MutationObserver 只保护 overlay 和其直接移除；同批记录逆序恢复并在卸载时断开，高频业务 children 更新不触发修复。

## 测试证据

- Unit（本轮定向通过）: `Watermark.test.tsx` 14 项覆盖文本/多行、图片 load/error 去重与 URL 变化、几何归一、对象/callback ref、篡改逆序恢复、外部节点边界、observer 缺失/关闭、动态 children、SSR markup 与 hydration；另有 1 项 node-environment SSR 覆盖无 window/document 输出。
- Story interaction: `DynamicContent` 验证业务内容更新且水印 overlay 保持稳定；仓库门禁 `check-storybook-links` 本地验证 `play-fn 81/81`（81 个 Storybook title 均至少一个有意义 play）。
- `ImageWithFallback` Story 主动派发 error 并等待文本 fallback；`HostBoundary` 固化 wrapper + overlay 双重裁界与 Figma `clipsContent=true` 一致。
- Storybook 浏览器矩阵：本地扫描器在 390×844 视口验证 444 个 Story × 7 场景（Light、Dark、en-US、RTL、reduced-motion、200% 字体、forced-colors），共 3,108 个组合；有 play 的 Story 必须先返回 `storyFinished=success`，再运行 axe WCAG A/AA，结果为 0 违规、0 `pageerror`。
- 官网 Next 运行时：本地 production build 在 390×844 下逐页验证 68 个组件页的 Light/Dark（136 场景）；主题恢复、H1/预览/API 结构、React `pageerror` / `console.error`（含 hydration mismatch）和 axe WCAG A/AA 均通过。
- Bundle：Rollup tree-shaken ESM（React 与包 peer dependencies external）单一公开值 gzip 2276 B / 32768 B 预算，组合 Brotli 2050 B；共享样式由应用单独导入一次。
- SSR/hydration: jsdom 定向测试覆盖 stable pattern markup 和 hydrateRoot 节点复用；隔离 Next 16 生产构建浏览器路径已在本地完整门禁通过。
- RTL: 无方向性布局；bidi 内容待真机。
- Reduced motion: 不适用，无动画。
- Mobile Chromium/WebKit E2E: `renders a non-interactive watermark and restores its removed overlay` 已在本地完整门禁的两种引擎通过，验证 overlay 不拦截交互、移除恢复与属性篡改恢复。
- Chromatic Light/Dark: Story 已建立，基线待执行。
- Real device: 未执行。
