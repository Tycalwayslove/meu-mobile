# Badge

## 当前能力

- 支持 standalone/anchor overlay、dot、短内容、数字 max、showZero、bordered、逻辑 offset 和五种 tone。
- 数字超过有限 max 显示 `max+`；0 默认隐藏、showZero 时显示。dot 不渲染 content。
- `null`、boolean、空数组与空字符串不生成空 marker；仅有这些空节点的 children 不会误进入锚点定位。
- 无 label 的 dot 装饰性隐藏；label 为 dot 提供状态含义，也可替换计数的可访问名称。
- RTL 定位与 forced-colors 已处理；组件无动画。

状态为 `verification`；本地结构、视觉场景与双引擎消费路径已完成，最终 Chromatic 基线和真机状态朗读仍是发布门禁。

## 何时使用

用于未读数、短状态或锚点角标。状态 dot 必须配 label，或在相邻可见文本中表达同一含义。

## 何时不要使用

长提示用 Tag/Text；进度用 Progress；需要点击时让锚点自身成为 Button/Link，不给 Badge 增加点击处理。

## 结构与状态

根为 span，marker 为内部 span。带 children 时 marker 绝对定位；状态为 dot/content/empty/standalone，tone 单独通过 data 属性表达。

## 基础用法

```tsx
<Badge content={128} max={99} label="99 条以上未读消息">
  <IconButton aria-label="消息" />
</Badge>
```

## 受控与非受控

不适用。Badge 纯由 props 派生，不维护计数状态。

## 表单集成

不适用。Badge 不是表单控件。

## Props

API 由 `BadgeProps` 生成。number content 会截断并夹紧到零，非有限 count 归零；max 仅处理 number content，非有限 max 不截断。offset 为逻辑 inline-end、block-start 的像素偏移，非有限 offset 归零。React 空节点不创建空角标或伪锚点。

## Events

没有专有事件。根原生 span 事件可透传，但不应借此把 Badge 当按钮。

## Ref 与命令式方法

ref 指向根 span；无命令式方法。

## 键盘操作

| 按键   | 行为                                   |
| ------ | -------------------------------------- |
| 不适用 | Badge 不进入 Tab；锚点控件负责键盘操作 |

## 触摸与手势

Badge 不创建触摸目标。锚点若可操作必须自行满足至少 44×44。

## 无障碍

数字/文字 content 默认参与名称计算；label 可提供更完整含义。无 label dot 使用 aria-hidden，避免只朗读无意义图形。tone 不能独立承载成功/警告/失败语义。

## 动效

不适用。无进入、计数跳动或循环动画，因此 reduced-motion 无额外分支。

## 主题与定制

颜色与圆角来自 Meu Token；forced-colors 使用 CanvasText/Canvas。稳定入口为 tone、dot、bordered、offset、className/style 和 data 属性。

## SSR 与 Next.js

纯 props render，无 effect、随机 ID 或浏览器读取；服务端和客户端结构稳定。

## RTL 与国际化

marker 使用 inset-inline-end；RTL 时翻转位移方向。`max+` 未本地化，复杂数字格式请直接传格式化后的 ReactNode 与 label。

## 浏览器与 WebView

依赖标准 inline-flex、逻辑定位和 CSS 自定义属性。Chrome/WebView 70、iOS 13 语法基线可用；非常旧 WebView 的逻辑属性需在目标设备复验。

## 边界情况与已知限制

- content 为长 ReactNode 时视觉限制为 12ch 并省略；读屏仍可读取 DOM 内容。
- 不提供 live region；业务需要动态公告时在外部使用独立 `aria-live` 文本。
- max 小于零被截为 0；NaN/Infinity max 不参与截断。

## 性能预算

常数节点，无监听器和布局测量；大量列表成本主要来自锚点内容。

## 测试证据

- Unit: `Badge.test.tsx` 覆盖 zero/max、dot label、tone 文本、RTL offset 与空 ReactNode 归一化。
- Story interaction: `Count` 验证独立计数与 accessibility tree 暴露；`check-storybook-links` 已验证全库 81/81 title 各至少一项关键 play，本 title 的 play 在本地扫描中返回 `storyFinished=success`。
- Storybook 浏览器矩阵：本地扫描器在 390×844 视口验证 490 个 Story × 7 场景（Light、Dark、en-US、RTL、reduced-motion、200% 字体、forced-colors），共 3,430 个组合；有 play 的 Story 必须先返回 `storyFinished=success`，再运行 axe WCAG A/AA，结果为 0 违规、0 `pageerror`。
- 官网 Next 运行时：本地 production build 在 390×844 下逐页验证 68 个组件页的 Light/Dark（136 场景）；主题恢复、H1/预览/API 结构、React `pageerror` / `console.error`（含 hydration mismatch）和 axe WCAG A/AA 均通过。
- Bundle：Rollup tree-shaken ESM（React 与包 peer dependencies external）单一公开值 gzip 1497 B / 32768 B 预算，组合 Brotli 1351 B；共享样式由应用单独导入一次。
- SSR/hydration: `Badge.ssr.test.tsx` 覆盖 overflow 与 dot label；隔离 Next 16 hydration 后 99+ 与 dot accessible label 保持一致，0 hydration/runtime error。
- RTL: Unit 覆盖 offset 数据归一化；逻辑定位由 CSS 实现，并已进入全库 RTL 与 forced-colors 浏览器矩阵。
- Reduced motion: 无动画，不适用。
- Mobile Chromium/WebKit E2E: 原子展示场景在两种引擎断言 `128 → 99+` 与 dot 的“店铺在线”名称，并与 Avatar 组合。
- Chromatic Light/Dark: Story 已建立，基线待执行。
- Real device: 待补。
