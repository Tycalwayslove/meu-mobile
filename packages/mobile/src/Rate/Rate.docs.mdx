# Rate

## 当前能力

- 交互态由透明原生 `input[type=range]` 覆盖整组装饰字符，保留触摸拖动、键盘、读屏、name/form/disabled 与 ref。
- count、整星/半星、受控/非受控、重复点当前值清零、三档尺寸、custom character、Field error 和本地化 value text。
- 数值按 1 或 0.5 对齐并限制 0..count；非法 count 回退 5，动态 count/allowHalf/value 仍保持 DOM、视觉与读屏一致。
- RTL 指针位置与原生 range 方向同步；半填充使用逻辑方向；forced-colors 保留系统 Highlight/GrayText。
- readOnly 输出为有名称和值的 meter 语义，同时保留 hidden input 的 FormData 和 input ref；disabled readOnly 不提交。
- Field 的 label/description/error 与调用方 `aria-labelledby` / `aria-describedby` 按 token 合并去重；中间有布局 wrapper 时仍通过 Field context 保留完整关系。

当前为 V2 `verification`，本地商业化门禁已完成且无本地缺口。单元、SSR、hydration、Storybook axe 与扩展场景矩阵均通过；Next-H5 集成场景已在移动 Chromium/WebKit 中验证键盘改值、可信鼠标 pointer 拖动、重复点击清零和表单提交。合成 pointercancel 的收敛已验证，但真实触摸取消、最终视觉审批与真机读屏仍待验收，因此产品状态仍不标记为 commercial。

## 何时使用

商品、服务、内容等 1–5/自定义上限的主观评分；零值表示尚未评分，允许半档时用户需要更细表达。

## 何时不要使用

- NPS、满意/不满意、离散文字含义或每档需解释时用 Radio/Selector。
- 显示统计平均值可用 readOnly；若只是装饰星图且无业务值，用普通 Icon/Text。
- 不用 character 传按钮、链接或其他交互内容，它被 aria-hidden 且会重复渲染。

## 结构与状态

根包含 interactive range 或 readOnly hidden input，以及 aria-hidden 字符层。状态 default/focus/error/readOnly/disabled，尺寸 small/medium/large。根暴露 component/size/state data，readOnly hidden input暴露 `data-meu-slot=form-value`。

## 基础用法

```tsx
<Field label="服务评分" error={error}>
  <Rate name="rating" allowHalf value={rating} onChange={setRating} />
</Field>
```

只读且随表单提交：

```tsx
<Rate aria-label="历史评分" name="previousRating" value={4.5} allowHalf readOnly />
```

## 受控与非受控

- value 不为 undefined 时受控；否则 defaultValue 初始化内部状态。
- 值按 active increment 对齐并 clamp；allowHalf/count 动态变化时显示立即重新规范化。
- 非受控 form.reset 返回时原生 DOM/FormData 已同步恢复最新 defaultValue，随后只同步 React 状态且不调用 onChange；取消 reset 时保持当前值，受控值由父级负责。
- programmatic value 变化不触发 onChange。

## 数值与清除

- count 转为至少 1 的整数；非有限 count 回退 5。
- allowHalf=false 四舍五入到整数，true 保留一位并按浏览器 step=0.5。
- pointer 点击当前档且 allowClear=true 时发布 0；一次 pointer 会话只要产生过原生 change，其尾随 click 就不会清零。pointer cancel 同样取消清除。键盘 Home 可原生到 0。
- allowClear=false 只关闭“重复点击清零”，不把 0 从值域移除；业务 required 应由 schema 明确验证 value > 0。

## 表单集成

- 交互态原生 range 透传 name/form/disabled/onInvalid 等；readOnly 使用 hidden input提交相同 value/name/form。
- disabled 在两种模式都不进入 FormData。readOnly 进入但不可聚焦；其 ref 指向 hidden input，适合读取 value/form，不应用于 focus。
- 交互态会继承 Field 的 native required，但 HTML required 对 range 的零值没有“未选择”语义，hidden input required 也无效；必评规则必须由 RHF/Zod/服务端检查大于 0。
- Field 提供 accessible name/description/error/必填说明；调用方 idref 与 Field idref 无损合并，error 映射到 interactive slider 或 readOnly meter 的 `aria-invalid` 和视觉 state。
- `MeuFormRate` 在 RHF 校验错误与调用方显式 `status="error"` 间取并集，不会在字段当前有效时抹掉业务错误视觉。

## Props

完整 API 由 types TSDoc/API Extractor生成。专有 Props：value/defaultValue、count、allowHalf、allowClear、character、getValueLabel、readOnly、size、status、onChange；其余来自原生 input（冲突字段除外）。

## Events

- `onChange(value)`：原生 range change 或重复 pointer 清除产生不同值时触发。
- 调用方 onPointerDown/onPointerCancel/onClick 保留；pointerdown/click preventDefault 可取消组件对应的清除跟踪/清除动作。
- 拖动可能高频 change；昂贵提交应由业务节流或在表单提交时处理。当前没有 onChangeComplete。
- readOnly/disabled 不触发 change。

## Ref 与命令式方法

ref 指向参与表单的真实 `HTMLInputElement`：交互态为 `type="range"`，readOnly 态为 hidden input。交互态可使用原生
`focus()`；readOnly hidden input 仅用于 FormData，不应命令式聚焦。视觉字符节点不是公开 ref。

## 键盘操作

interactive 依赖原生 range：Arrow keys 按 1/0.5 调整，Home 到 0，End 到 count，Page keys 按浏览器策略调整，Tab 聚焦/离开。readOnly 为静态 meter，不进入 Tab 顺序。

## 触摸与手势

透明 range 覆盖完整字符组，根高度至少 44px；可点选、拖动并响应系统 pointer cancel。`touch-action: pan-y` 明确保留页面纵向滚动并把横向评分交互留给控件，组件不使用 document 监听。相邻星视觉宽度为 30/34/38px，但整体可交互轨道高度满足移动目标。

## 无障碍

- interactive 是原生 slider，必须有 Field/ARIA name；`aria-valuetext` 默认中英文格式，也可显式传入或用 getValueLabel。
- character 层 aria-hidden，读屏只接收一个连续评分控件，不会重复朗读五个星。
- readOnly 是带 label/labelledby/describedby 的 meter 语义；Field label 命名控件，aria-valuemin/max/now/valuetext 独立表达评分值。
- error/disabled 使用 ARIA/原生属性和 data state，不只靠颜色。
- 无 Field/status error 时保留显式 `aria-invalid="false"`、`grammar`、`spelling`；grammar/spelling 触发错误视觉。Field/status error 优先输出 `true`，token 只位于 slider 或 meter，不复制到 hidden form input。

## 动效

没有持续动画，填充宽度即时变化，reduced-motion 不需额外动画分支。

## 主题与定制

主题使用 warning、border、accent、danger；forced-colors 禁用该区域自动重映射并显式使用 Highlight/GrayText，使填充与
空档可区分。稳定定制入口为 size、status、character、getValueLabel 与全局 Token；内部双层字符 DOM 不是样式 API。

## SSR 与 Next.js

- render 不读取 window/document/layout；服务端稳定输出 interactive range 或 readOnly meter+hidden input。getComputedStyle 仅在 pointer handler 中读取方向；独立 hydration 回归证明 range/hidden 节点 identity、change 与 FormData 保持有效。

## RTL 与国际化

- dir 应用于根和 range；flex 排列、半填充与点击映射均随 RTL。默认 value label 随 ConfigProvider locale 中英文切换。

## 浏览器与 WebView

构建产物通过 Chrome 70 / iOS 13 语法基线；不同 WebView 的 range 手势细节由原生实现负责。当前尚未完成 iOS 13
WKWebView 与 Android 低版本的功能真机矩阵，因此不能把语法兼容等同完整交互支持。

## 边界情况与已知限制

- 单个连续 slider 语义，不是五个 radio；不能逐星设置 tooltip/禁用/不同标签。
- custom character 必须是纯装饰且尺寸适合单行；复杂 ReactNode 会重复两次用于底色/填充裁切。
- readOnly ref 是 hidden input，不能 focus；静态可访问对象是外层 meter。
- required 非零评分、onChangeComplete、hover preview、键盘清除提示均未内建。
- pointer 清除通过目标几何判断，CSS transform 缩放下使用浏览器返回 rect，仍应在真实容器验收。

## 性能预算

渲染 O(count) 两层字符，无第三方运行时、持续 timer 或 document listener。count 不应设置到数百；大量列表建议 readOnly 并控制可见项。

## 测试证据

- Unit：3 个文件共 27 项，覆盖半值 change、readOnly meter/Field 值语义、嵌套 Field idref 合并、ARIA invalid token/优先级、非有限值与动态步长规范化、中英文/自定义值文本、RTL 重复清除、pointer cancel、调用方取消事件、拖动尾随 click 不清零、禁用与 readOnly FormData/ref、最新 defaultValue reset 与取消边界。
- SSR：覆盖 interactive range 与 readOnly meter/hidden form markup、token 归属、contextual error 覆盖、RTL/en-US/reduced-motion/dark provider 组合、非有限参数回退和禁用只读表单值。
- Hydration：`Rate.hydration.test.tsx` 证明 interactive range 与 readOnly hidden input 保持服务端 DOM identity，change/FormData 可用且无 recoverable error；hydration 后动态 count/allowHalf/value 更新仍复用原生 slider 节点。
- Story interaction：`NativeFormReset.play` 验证原生 reset；`PointerClear.play` 验证重复点击当前评分清零。
- Storybook 浏览器矩阵：Rate 的 16 个 Story 在 390×844 视口定向验证 7 个场景（Light、Dark、en-US、RTL、reduced-motion、200% 字体、forced-colors），共 112 个组合；play 必须先返回 `storyFinished=success`，再运行 axe WCAG A/AA，结果为 0 违规、0 `pageerror`。
- 官网 Next 运行时：本地 production build 在 390×844 下逐页验证 68 个组件页的 Light/Dark（136 场景）；主题恢复、H1/预览/API 结构、React `pageerror` / `console.error`（含 hydration mismatch）和 axe WCAG A/AA 均通过。
- Next-H5 交互 E2E：`binds stepper, slider, rate and selector values` 在 mobile Chromium 与 mobile WebKit 中聚焦 `MeuFormRate` 的原生 slider，以 ArrowRight 改值，并通过最终表单结果验证 `rating:4`；该证据覆盖键盘、hydration 和受控表单链路，不覆盖 pointer 清零或拖动。
- Next-H5 pointer E2E：`drags slider and rate with browser pointer events and resets cancelled sessions` 在两种移动引擎、390×844 视口中通过 `page.mouse` 产生 `isTrusted=true` 的 pointerdown，将评分拖至 4，并在同一坐标再次点击验证 `allowClear` 清零；随后在可信 pointerdown 会话中派发 `isTrusted=false` 的 pointercancel，验证取消回调收敛。该证据不等同于物理触摸或系统级取消。
- Bundle：Rollup tree-shaken ESM（React 与包 peer dependencies external）单一公开值 gzip 4795 B / 32768 B 预算，组合 Brotli 4266 B；共享样式由应用单独导入一次。
- Figma：`Meu/Rate` set `57:197`，15 variants；Light `451:104`、Dark `451:154`、QA `451:179`。Stepper/Slider/Rate/Selector 合并审计 fills 658/658、strokes 77/77、radii 209/209 全绑定，最小高度 44px，未命名节点 0。
- 待补：iOS/Android 物理触摸 drag、系统 pointercancel 与滚动竞争；forced-colors 聚焦与半星截图、Chromatic Light/Dark 视觉基线、iOS VoiceOver 与 Android TalkBack。
