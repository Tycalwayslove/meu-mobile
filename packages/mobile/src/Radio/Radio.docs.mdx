# Radio / RadioGroup

## 当前能力

- 原生 radio input；RadioGroup 统一稳定 name，保持浏览器互斥、Tab 和方向键行为。
- 支持 `string | number` 值、受控/非受控、controlled empty (`value=null`)、required、disabled、readOnly、错误态和三档尺寸。
- 非受控 Group 监听原生 form reset 并恢复 defaultValue；checked 值按原生 FormData 提交。
- standalone 同名 Radio 会同步原生互斥后的 React 视觉状态，受控同伴仍保持调用方值为事实源。
- Field label/description/error/required 与调用方 IDREF 无损组合。
- 没有 Field/status 错误时，`aria-invalid="false"`、`grammar` 和 `spelling` 保持原 token；上下文错误优先输出 `true`。Group 错误只在语义根输出，子 Radio 继承错误视觉。
- 选择目标至少 44×44，并使用移动 tap 优化；RTL 使用自然文档流；forced-colors（含 disabled GrayText）和 reduced-motion 有静态降级。

状态为 `verification`；Unit/SSR/Story contract、本地 axe 与 Next H5 移动 Chromium/WebKit 的基础选择路径已建立，Chromatic 主题最终审批和真机读屏尚未达到发布证据线。

## 主流基线与取舍

V2 对照了 [Ant Design Mobile Radio](https://mobile.ant.design/components/radio/) 的 string/number、Group 和移动端 label 模型，以及 [MUI RadioGroup](https://mui.com/material-ui/react-radio-button/) 的 shared name、controlled value、原生键盘和错误反馈。Meu 不增加自定义 icon 或命令式选择 API，优先保证 native radio name group、FormData 与浏览器方向键是一致事实源。

## 何时使用

用于一个集合中必须或可以只选择一项的稳定选项，例如配送方式、支付方式。优先使用 RadioGroup，单独 Radio 仅适用于已有原生 name 管理或布尔“设为默认”场景。

## 何时不要使用

- 多选使用 CheckboxGroup。
- 两态设置立即生效使用 Switch。
- 选项数量很大、需要搜索或远程加载时使用 Picker/Select 类组件。

## 结构与状态

Radio DOM 为 input → indicator → label。根暴露 `data-meu-component="radio"`、`data-size`、`data-readonly`、`data-state="unchecked|checked|readonly|disabled"`。Group 使用 `role="radiogroup"` 并暴露 default/error/readonly/disabled。

## 基础用法

```tsx
<RadioGroup name="shipping" defaultValue="standard" required onChange={setShipping}>
  <Radio value="standard">标准配送</Radio>
  <Radio value="express">急速配送</Radio>
</RadioGroup>
```

## 受控与非受控

- Group `value !== undefined` 时受控；`null` 是明确的受控空值。
- 非受控 Group 由 defaultValue 初始化并在选择时更新；form reset 回到 defaultValue。
- standalone Radio 以 checked/defaultChecked 选择受控或非受控；同一 form/name 下会在原生 change 后同步所有 Meu Radio 的 checked 视觉与 `data-state`。业务集合仍优先使用 RadioGroup，以集中管理 value、label、required 和 invalid。

## 表单集成

- Group 的所有 Radio 共享调用方 name；省略 name 时使用 React useId 生成同一 SSR/hydration 树内稳定的名称。
- 选中项以 `name=value` 进入 FormData；disabled 原生排除。
- required 同时位于 radiogroup (`aria-required`) 与原生 radio name group，触发浏览器 constraint validation。
- readOnly 保持当前值可聚焦、可提交并阻断选择。radiogroup 使用 `aria-readonly`；HTML radio 没有 native readonly，组内子项由组传达，standalone 以 `aria-disabled` 表达不可修改并通过事件回滚保证值不变。
- 官方 `MeuFormRadioGroup` 以 RHF 标量值为受控事实源，并合并 RHF invalid 与调用方显式 `status="error"`；任一来源判错都保留错误呈现。

## Props

API 表由 TypeScript/TSDoc 和 API Extractor从 `RadioProps`、`RadioGroupProps` 生成。`value` 只接受 string/number，避免 DOM 提交和严格相等身份出现对象序列化歧义。

## Events

- `Radio.onChange(checked, event)` 在 standalone 或组内选中后触发；原生 radio 用户操作只产生 checked=true。
- `RadioGroup.onChange(value, event)` 提供完整选中值和原始 input change event。
- disabled/readOnly 不触发值回调；readOnly 原生 click 仍可被调用方观察但已 preventDefault。

## Ref 与命令式方法

Radio ref 指向原生 `HTMLInputElement`。Group ref 指向 radiogroup div。业务聚焦错误组选项时应聚焦当前 checked radio，若无选择则聚焦第一个 enabled radio。

## 键盘操作

| 按键            | 行为                                            |
| --------------- | ----------------------------------------------- |
| Tab / Shift+Tab | 进入/离开原生同名 radio group                   |
| Arrow keys      | 按浏览器顺序移动选择；readOnly 时回滚并保持原值 |
| Space           | 选择聚焦项；readOnly 时保持原值                 |

不实现自定义 roving tabindex，避免覆盖 iOS/Android 原生表单行为。

## 触摸与手势

每个 label 是完整触摸目标，最小宽高 44×44 CSS px。组件无拖动、长按或横滑；horizontal 在窄屏自动换行。

## 无障碍

- radiogroup 接受 `aria-label` 或 `aria-labelledby`；Field 可见 label 默认通过后者命名。
- required/invalid/description/error 归属 radiogroup；invalid 向子 Radio 传播错误视觉，但不会凭空给每个子项添加 `aria-invalid="true"`。子 Radio 显式提供的 ARIA invalid token 仍保留。
- indicator 仅视觉；checked、required、disabled 均由原生 input 传达。
- forced-colors 选择环使用系统 Highlight；状态不只依赖主题色。

## 动效

选中点只使用 opacity/scale 短过渡；reduced-motion 下为 1ms，无循环动画。

## 主题与定制

稳定入口为 size/status/direction、根 className/style、data 属性和 Token。内部 indicator 与生成 class 不属于公开 API。

## SSR 与 Next.js

render 不读取浏览器全局。useId 生成的 name 在相同服务端/客户端树中稳定；调用方不要基于 `window` 改变首屏选项顺序。reset 监听仅在客户端 effect 注册。

`Radio.hydration.test.tsx` 验证 useId name 在同一服务端/客户端树中一致、DOM 节点复用且 hydration 后可选择。

## RTL 与国际化

使用 flex gap 和 inline flow，RTL 下选项/文字自然镜像；圆形 indicator 无方向性。长文本允许换行，业务负责 label 翻译和排序含义。

## 浏览器与 WebView

依赖 React 19、原生 radio、FormData、form reset 和标准 CSS，目标为 iOS Safari/WKWebView 15+、Android Chrome/WebView 89+。方向键在移动软键盘通常不可见，但蓝牙键盘和桌面 WebView 保持原生行为。

## 边界情况与已知限制

- HTML radio 不提供 readonly；本组件提供的 readOnly 是可聚焦、可提交的交互冻结，不等同 disabled。
- standalone 同名 Radio 已同步 Meu 组件同伴；若同一 name 混入第三方自绘 Radio，其视觉状态仍由第三方自行负责，推荐统一使用 RadioGroup。
- generated name 仅保证 React 树内稳定，不应被后端当作业务字段名；表单提交必须显式 name。
- 动态删除当前选项不会自动选择备用项，由业务决定空值与校验。

## 性能预算

每个 Group 仅在非受控 form 场景注册一个 reset 监听；每个具名 standalone Radio 使用 element-local 同步监听，不注册 document/window 全局监听，不测量布局或引入第三方运行时依赖。
