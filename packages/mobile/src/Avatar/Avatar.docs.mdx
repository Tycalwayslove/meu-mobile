# Avatar

## 当前能力

- 基于 Image 的固定尺寸头像，支持 circle/rounded/square、三档预设和安全归一化的数值像素尺寸。
- 图片 loading/loaded/error、空源、失败回退、显式 initials、自定义 fallback、alt、root/image ref 已验证。
- 原生响应式图片与请求控制已透传：srcSet、sizes、loading、decoding、fetchPriority、crossOrigin、referrerPolicy、draggable；objectPosition 可调整圆形裁切焦点。
- 可选 fallbackSrc 在主源失败后尝试一次备用图片，再落到内容 fallback；源变化由 Image 状态机重新开始，不自行循环重试或缓存失败。
- 32px small 不再继承通用 Image 状态层的 44px 最小尺寸与 padding；RTL 无方向性布局；forced-colors 只保留 Avatar 外轮廓，避免双边框。图片淡入的 reduced-motion 降级由 Image 实现。

状态为 `verification`；本地 Unit/SSR/hydration、Story 和 Next H5 移动 Chromium/WebKit 已覆盖基础、慢加载、失败与换源恢复边界，最终 Chromatic 视觉审批和真机读屏尚未完成。

## 何时使用

用于人员、店铺或组织的紧凑身份图像。网络图像不可靠时传短 initials 或可识别 fallback。

## 何时不要使用

商品图、响应式内容图使用 Image；可点击账户入口应由 Link/Button 包裹，Avatar 自身不承担交互语义。

## 结构与状态

根为非交互 span，内部 Image 负责 loading/loaded/error。根暴露 `data-meu-component`、`data-shape`、`data-size`；Image 暴露 `data-state`。Avatar 没有 pressed/selected/disabled 状态。

## 基础用法

```tsx
<Avatar
  src={user.avatarUrl}
  srcSet={`${user.avatarUrl} 1x, ${user.avatar2xUrl} 2x`}
  sizes="44px"
  alt={user.displayName}
  initials="LX"
  loading="lazy"
  objectPosition="50% 25%"
/>
```

## 受控与非受控

不适用。组件无业务状态；`src`、`alt`、`initials` 和 `fallback` 始终由调用方决定。

## 表单集成

不适用。Avatar 不是表单控件，不提交 FormData。

## Props

API 由 `AvatarProps` 生成。fallback 优先级固定为 `fallback`、显式 `initials`、alt 首字符；空 alt 表示装饰图像。数值 size 非有限时回退 44px，有限值最小 1px。

| Prop              | 类型                                   | 默认值    | 契约                                                         |
| ----------------- | -------------------------------------- | --------- | ------------------------------------------------------------ |
| alt               | string                                 | 必填      | 身份图像名称；仅纯装饰时传空字符串                           |
| src / srcSet      | string                                 | undefined | 图片候选；空白 src 视为缺失，srcSet 可独立提供候选           |
| sizes             | string                                 | undefined | srcSet 使用宽度描述符时的原生尺寸提示                        |
| fallback          | ReactNode                              | undefined | 最高优先级 loading/error/空源内容                            |
| fallbackSrc       | string                                 | undefined | 主图片失败后尝试一次的备用 URL                               |
| initials          | string                                 | undefined | 次级 fallback；渲染前 trim，视觉层统一 uppercase             |
| size              | small / medium / large / number        | medium    | 32 / 44 / 56px 或归一化后的像素值                            |
| shape             | circle / rounded / square              | circle    | 裁切形状                                                     |
| fit               | CSS object-fit                         | cover     | 图片缩放方式                                                 |
| objectPosition    | CSS object-position                    | 50% 50%   | 裁切焦点，写入 Avatar 私有 CSS 变量                          |
| loading           | eager / lazy                           | eager     | 原生加载策略                                                 |
| decoding          | auto / async / sync                    | async     | 原生解码提示                                                 |
| fetchPriority     | high / low / auto                      | undefined | 原生请求优先级提示                                           |
| crossOrigin       | anonymous / use-credentials / 空字符串 | undefined | 原生 CORS 模式                                               |
| referrerPolicy    | 原生 referrer policy                   | undefined | 图片请求来源策略                                             |
| draggable         | boolean                                | false     | 原生拖拽行为                                                 |
| ref / imageRef    | Ref<span> / Ref<img>                   | undefined | 稳定根节点 / 当前存在的原生图片节点                          |
| className / style | 原生 span 属性                         | undefined | 只作用于 Avatar 根；数值 size 与 objectPosition 保留内部变量 |

其余允许的 `HTMLAttributes<HTMLSpanElement>` 透传根节点；`children`、`dangerouslySetInnerHTML`、根级 `onLoad/onError` 不在公开接口中，避免破坏内部状态结构。

## Events

| Event          | 触发时机                             | 状态结果                                          |
| -------------- | ------------------------------------ | ------------------------------------------------- |
| onLoad(event)  | React 观察到当前 img 的 native load  | Image 进入 loaded，然后调用回调                   |
| onError(event) | React 观察到当前 img 的 native error | 有 fallbackSrc 时切到备用 loading，否则进入 error |

每个 React 已观察到的原生事件透传一次；正常的 primary 与 fallbackSrc 双失败可能收到两次 onError。hydration 前已经完成的缓存请求会恢复状态，但不会合成已错过的 SyntheticEvent。Avatar 不合成重试事件，不自动改写调用方 src。调用方变更 src/srcSet/fallbackSrc 时，状态机会以新 source key 回到 loading。

## Ref 与命令式方法

`ref` 指向稳定根 span；`imageRef` 在实际 img 存在时指向它。primary 切换到 fallbackSrc 时复用 img；最终 error/空源时 img 被卸载，imageRef 为 null。

## 键盘操作

| 按键   | 行为                                         |
| ------ | -------------------------------------------- |
| 不适用 | Avatar 不可聚焦；交互由外层 Link/Button 提供 |

## 触摸与手势

不适用。medium 为 44×44，但 small 为 32×32，不能把静态 Avatar 当独立触控目标；交互外层必须满足至少 44×44。

## 无障碍

非空 alt 为图像名称，失败回退仍以同一名称暴露；空 alt 时图片与文字/custom fallback 整体装饰性隐藏。loading fallback 在原生 img 仍存在时 aria-hidden，避免同一身份被朗读两次。initials 只是视觉回退，不能替代准确 alt。自定义 fallback 不得包含按钮、链接、输入框或 live region。

## 动效

Avatar 自身无动画；Image 的 opacity 淡入使用全局 motion，并在 reduced-motion 下将过渡关闭为 0ms。

## 主题与定制

背景、文字、圆角和字体来自 Meu Token；forced-colors 使用 Canvas/CanvasText 且只绘制外层轮廓。稳定入口为 shape、size、fit、objectPosition、className/style 与 data 属性；`data-meu-avatar-fallback` 只标识内部 fallback，不是插槽 API。

## SSR 与 Next.js

render 不读取浏览器全局、随机值或布局信息。空源服务端直接输出可访问 fallback；有源时服务端和客户端首帧都输出 loading 占位与 img。hydrate 后 Image effect 才检查缓存图片的 complete/naturalWidth，不改变首帧结构。`Avatar.hydration.test.tsx` 断言无 recoverable error、ref 恢复和 hydrate 后 error 回退。

## RTL 与国际化

无方向性排列。默认 fallback 仅取 alt 的首个 Unicode code point 并大写；复杂姓名缩写应显式传 initials，业务负责本地化。

## 浏览器与 WebView

正式支持 React 19、iOS Safari/WKWebView 15+ 与 Android Chrome/WebView 89+；Chrome 70 / iOS 13 仅是构建语法扫描和观察档，不构成完整运行时承诺。组件依赖原生 img/alt/srcSet/sizes/object-fit、CSS Grid 与自定义属性；旧 WKWebView 的 lazy loading 可能退化为 eager，decoding/loading 也只是浏览器提示。当前 Playwright mobile Chromium/WebKit 在 10,000px 视口外均延迟 lazy Avatar 请求，滚入视口后才发起；该结果验证当前支持引擎，但不把浏览器提示提升为组件强制调度保证。跨域是否成功仍由图片服务器 CORS/Referrer 配置决定。

## 边界情况与已知限制

- 不内建 picture/source、循环重试、缓存、上传或 Next/Image 优化；需要这些能力时使用 Image 或业务图片层。
- 自定义 fallback 应是短静态内容，不放按钮或链接。
- 1–31px 数值头像可显示，但不满足触控或可读性建议。
- 派生 fallback 只取 trim 后 alt 的首个 Unicode code point；组合 emoji、复姓或多词姓名应显式传业务本地化 initials。

## 性能预算

单个 Avatar 为常数节点；网络与解码成本属于图片资源。列表应使用 lazy loading、合理尺寸和 CDN 裁剪。

## 未来变更规则

1. fallback 优先级、alt 语义、非交互 span 根、ref 指向和 `data-meu-component/data-shape/data-size` 属于兼容契约；改变它们必须按破坏性变更处理。
2. 新图片能力优先以可选 prop 透传且保持服务端首帧确定；不得因浏览器能力检测造成 hydration 分叉。
3. 不在 Avatar 内加入点击、在线状态、角标或上传逻辑；组合行为由 Button/Link、Badge、ImageUploader 承担。
4. 新状态必须同时补 Unit、SSR/hydration、Story 和无障碍说明；涉及视觉时补 Light/Dark、RTL、forced-colors、200% 字体和 reduced-motion 证据。
