# Collapse

## 当前能力

Collapse 是基于原生 `button` 的 disclosure group，支持多项展开和 accordion 单项展开、受控与非受控状态、条目或整组禁用、稳定 ARIA 关联、动态条目、外接键盘标题导航、嵌套、未知高度展开动画、RTL、SSR/hydration 和 React 19 ref。

组件会持续挂载 panel，因此输入值、滚动位置和子组件状态在收起后仍然保留。收起 panel 同时使用 `inert`、`aria-hidden`、`visibility: hidden` 和零行网格，避免隐藏控件进入焦点或读屏顺序。

## 何时使用

- FAQ、配送或售后规则、筛选说明等可按需阅读的次要内容。
- 多项内容彼此独立时使用默认 multiple 模式。
- 内容较长且通常只需要阅读一项时使用 `accordion`。

## 何时不要使用

- 关键错误、付款结果、主要操作和用户必须同时比较的内容不应隐藏。
- 页面级导航使用 Tabs、SideNav 或 NavBar。
- 仅有一段可展开内容时，可以直接使用原生 `details/summary`；Collapse 的价值在于组状态、受控协调和统一视觉。

## 基础用法

```tsx
import { Collapse } from "@meu/mobile";

<Collapse
  aria-label="配送与售后"
  defaultValue={["delivery"]}
  items={[
    { value: "delivery", title: "配送范围", content: "支持中国大陆大部分城市配送。" },
    { value: "returns", title: "退换规则", content: "签收后 7 天内可申请退换。" }
  ]}
/>;
```

## 受控与非受控

```tsx
const [openItems, setOpenItems] = useState<readonly string[]>(["delivery"]);

<Collapse accordion items={items} value={openItems} onChange={setOpenItems} />;
```

- 提供 `value` 时为受控模式，视觉状态只跟随调用方下一次传入的值。
- 未提供 `value` 时，`defaultValue` 只在首次挂载读取。
- 默认允许多个 panel 同时展开；`accordion` 将有效值归一为最多一项，并允许再次点击后全部收起。
- 未知值和重复状态值会被忽略。重复 item `value` 采用 first-wins，只渲染第一项，避免重复 React key、DOM ID 和 ARIA 关系。
- 非受控模式中，已删除 item 的展开值在布局提交后永久清理；同值 item 再加入时不会意外恢复旧状态。

## 表单集成

Collapse 本身不提交值，所有 trigger 固定为 `type="button"`。panel 持续挂载，因此内部表单值、dirty/touched 和局部状态在收起后保留；收起时 `inert`、`aria-hidden` 与 `visibility` 共同把内部控件移出交互和读屏路径。

## Items

| 字段        | 类型        | 默认值  | 说明                                                             |
| ----------- | ----------- | ------- | ---------------------------------------------------------------- |
| `value`     | `string`    | 必填    | 唯一且稳定的业务身份，同时用于状态、React key 和稳定 ARIA ID     |
| `title`     | `ReactNode` | 必填    | trigger 可见标题，不得包含按钮、链接或其他交互元素               |
| `content`   | `ReactNode` | 必填    | 持续挂载的 panel 内容，可以包含表单或嵌套 Collapse               |
| `extra`     | `ReactNode` | -       | 非交互尾部元数据；`0` 和空字符串会保留                           |
| `disabled`  | `boolean`   | `false` | 禁用当前 trigger；若当前 panel 已展开，其内容仍保持可用          |
| `ariaLabel` | `string`    | -       | 图标标题等无法从可见内容得到名称时，覆盖 trigger accessible name |

## Props

| Prop                 | 类型                                                              | 默认值    | 说明                                                           |
| -------------------- | ----------------------------------------------------------------- | --------- | -------------------------------------------------------------- |
| `items`              | `readonly CollapseItem[]`                                         | 必填      | disclosure 条目；重复 value first-wins                         |
| `value`              | `readonly string[]`                                               | -         | 受控展开值                                                     |
| `defaultValue`       | `readonly string[]`                                               | `[]`      | 非受控初始展开值                                               |
| `accordion`          | `boolean`                                                         | `false`   | 最多展开一项                                                   |
| `disabled`           | `boolean`                                                         | `false`   | 禁用所有 trigger，不强制隐藏已展开内容                         |
| `headingLevel`       | `1 \| 2 \| 3 \| 4 \| 5 \| 6`                                      | `3`       | 每个 accordion header 的文档大纲级别                           |
| `keyboardNavigation` | `boolean`                                                         | `true`    | 启用标题间 ArrowUp/ArrowDown/Home/End 焦点导航                 |
| `region`             | `boolean`                                                         | `true`    | panel 是否声明 `role=region`；超过约 6 个并行 panel 时建议关闭 |
| `arrow`              | `ReactNode \| (expanded: boolean) => ReactNode`                   | Meu 箭头  | 装饰性尾部指示器；包装层负责方向与展开旋转                     |
| `variant`            | `"plain" \| "card"`                                               | `"plain"` | 只改变表面边界，不改变行为                                     |
| `onChange`           | `(value: string[], event: MouseEvent<HTMLButtonElement>) => void` | -         | enabled trigger 计算下一值后触发                               |
| `ref`                | `Ref<HTMLDivElement>`                                             | -         | 指向根 `div`                                                   |
| 原生 `div` 属性      | `ComponentProps<"div">`                                           | -         | `id`、`role`、`dir`、ARIA、data 属性和根事件均透传             |

`children`、原生 `defaultValue` 和原生 `onChange` 被组件契约替换。`data-meu-component`、`data-state`、`data-disabled`、`data-variant` 可用于测试和观测；生成的 class 名不是公共 API。

## Events

`onChange(nextValue, event)` 同时覆盖点击、Enter 和 Space 的原生 button 激活。它不是可取消事件：

- 非受控模式在同一次激活中更新内部值并回调。
- 受控模式只回调；调用方决定是否接受 `nextValue`。
- 原生 disabled trigger 不派发激活回调。
- ArrowUp、ArrowDown、Home 和 End 只移动焦点，不改变展开值，也不调用 `onChange`。

## Ref 与命令式方法

React 19 `ref` 指向根 `HTMLDivElement`。组件不暴露命令式 open/close 方法；业务可以通过 `value` 驱动状态，通过根 ref 查询 `[data-meu-collapse-trigger]` 完成少量原生聚焦需求。根 `onFocusCapture` 和 `onBlurCapture` 会在内部焦点追踪后继续调用传入的处理器。

## 键盘操作

| 按键              | 行为                                                   |
| ----------------- | ------------------------------------------------------ |
| `Tab / Shift+Tab` | 按 DOM 顺序经过 enabled triggers 和已展开 panel 内控件 |
| `Enter / Space`   | 原生切换当前 disclosure                                |
| `ArrowDown`       | 聚焦下一个 enabled header，末尾循环到开头              |
| `ArrowUp`         | 聚焦上一个 enabled header，开头循环到末尾              |
| `Home / End`      | 聚焦第一个或最后一个 enabled header                    |

动态更新时，value 派生的 trigger/panel ID 不随重排改变。若当前聚焦 header 被删除或禁用，焦点移动到原索引之后最近的 enabled header，找不到时回退到之前最后一项；用户已经把焦点移到 Collapse 外部时不会抢回。嵌套 Collapse 只处理自己最近的根节点，不会驱动外层 header。

如宿主页面要自行绑定这些方向键，可设置 `keyboardNavigation={false}`。垂直标题导航不按 RTL 交换 ArrowUp/ArrowDown。

## 结构与状态

DOM 结构为 `group → item → heading → button + region`：

- heading 只包含 trigger button，级别由 `headingLevel` 决定。
- button 提供 `aria-expanded` 和 `aria-controls`。
- panel 通过 `aria-labelledby` 回指 button。
- `region={false}` 只移除 panel landmark，不影响 disclosure 关联、隐藏或动画。
- item 和 group disabled 都落实为各 trigger 的原生 button `disabled`。根不自动设置 `aria-disabled`，因为已展开 panel 内的链接、输入和按钮仍然可用；把 `aria-disabled` 放在共同祖先上会错误地把这些后代也声明为不可用。

## 无障碍

每个 heading 只包装一个原生 button，button 与 panel 通过 `aria-controls` / `aria-labelledby` 双向关联；展开状态使用 `aria-expanded`。inactive panel 不从 DOM 移除，但会退出焦点和可访问性树。条目多于约六项时可设置 `region={false}`，减少 landmark 噪音。

## 嵌套

嵌套 Collapse 可以放在外层 `content` 中。为内外组使用不同的 `aria-label`，并让内层 `headingLevel` 比外层更深。内层 value、ID、键盘与焦点恢复均独立。如果页面存在很多展开 panel，关闭内层或大列表的 `region`，避免读屏 landmark 噪音。

## 动效

panel 使用 CSS Grid `0fr → 1fr` 和 opacity 过渡，不读取 `scrollHeight`，因此文字换行、异步内容和嵌套内容的未知高度可以自然展开，也不会产生 JS 测量循环。进入使用 `--meu-motion-enter`，退出使用 `--meu-motion-exit`；收起完成前延迟切换 visibility。

`ConfigProvider motion="reduced"` 会把 motion Token 归零，系统 `prefers-reduced-motion: reduce` 也将过渡压缩到 1ms。组件不会循环播放动效。

## 触摸与手势

整行 trigger 的最小高度为 52 CSS px，符合 44×44 最小目标。标题和 extra 都允许换行、`overflow-wrap:anywhere`，不会依赖固定宽度截断；内容也可以自然增长。`extra` 仅用于简短元数据，复杂操作应放进 panel，避免在 button 内嵌交互控件。

## RTL 与国际化

- 标题、extra、padding 和间距使用逻辑方向。
- 默认箭头从 `ConfigProvider dir` 或根的显式 `dir="ltr|rtl"` 决定收起方向，展开时统一向下。
- `dir="auto"` 会原样透传给根文本方向，但装饰箭头使用 ConfigProvider 方向；需要确定箭头方向时传明确的 `ltr` 或 `rtl`。

可见标题、extra、panel 内容与 trigger `ariaLabel` 都由调用方本地化；组件不拼接业务状态句子。

## 主题与定制

- 颜色、边界、圆角和 motion 全部使用 Meu Token。
- forced colors 中保留 CanvasText 分隔线、ButtonText 焦点和箭头；disabled 不使用 opacity 作为唯一表达。

## SSR 与 Next.js

组件无 Portal、ResizeObserver 或服务端浏览器访问。`useId` 提供实例前缀，item value 的 Unicode code point 提供与位置无关的后缀，因此相同首屏 props 下 SSR/hydration 关系一致，hydration 后重排也不会改变 ID。

## 浏览器与 WebView

完整动态高度插值依赖浏览器支持 CSS Grid track animation，因此属于渐进增强，不作为 iOS 15 / Chrome 89 静态支持档的硬保证；不支持插值的内核会离散切换，并可能在过渡中途出现一次高度跳变，但 button/region/inert/visibility 语义保持不变。`inert` 缺失时，`visibility:hidden` 仍阻止收起 panel 的聚焦与读屏暴露。

## 性能预算

默认所有 panel 持续挂载，DOM 规模为 `O(items + content)`，这是表单状态保留和流畅退出动画的明确取舍。对大量或昂贵内容，应由业务分页、虚拟化或延迟获取数据；不要把数百个富内容 panel 同时放入一个 Collapse。公共 bundle 数值由全库最终批次统一重新生成，本批不触发发布构建、Chromatic 或 Vercel。

- Bundle：Rollup tree-shaken ESM（React 与包 peer dependencies external）单一公开值 gzip 5939 B / 32768 B 预算，组合 Brotli 5264 B；共享样式由应用单独导入一次。

## 边界情况与已知限制

- `value` 必须是稳定业务身份。修改 value 等价于删除旧 item 并创建新 item，panel React 状态会重置。
- `title`、`extra` 和 `arrow` 都在 button 内，不允许嵌套 button、link、input 或其他交互元素。
- 当前没有 lazy/destroyInactive 模式，收起不释放内容 DOM；这保证退出动画和表单状态一致。
- 动态内容在“已展开”状态下改变高度会直接重新排版；进入/退出过程才应用 disclosure 过渡。
- 真机 VoiceOver/TalkBack 和高 item 数性能记录仍待最终发布候选批次补齐。
