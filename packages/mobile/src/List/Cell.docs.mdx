# Cell

## 当前能力

移动端信息行，根据 `href`、点击能力或静态用途分别输出原生 anchor、button 或 div；支持 title/description/prefix/extra/suffix、箭头、禁用、loading、RTL、长内容和 List 列表语义。

## 何时使用

用于设置入口、订单摘要、详情跳转和单次即时操作；整行语义与视觉点击区域保持一致。

## 何时不要使用

不要在交互 Cell 内嵌套另一个链接、按钮或表单控件；选择字段使用 Radio/Checkbox/Selector，大量数据使用 VirtualList。

## 结构与状态

`frame[role=listitem] → a|button|div + optional divider`。状态包括 static、interactive、disabled、loading、active press 与 focus。

## 基础用法

```tsx
<Cell title="收货地址" description="北京市朝阳区" href="/address" />
```

## 受控与非受控

Cell 不持有业务选中值或请求。`loading` 是由调用方控制的忙碌标记；请求成功、失败、取消和卸载时都应由业务收敛。

## 表单集成

动作模式默认 `type=button`，不会意外提交祖先表单；只有调用方显式使用 submit 才参与原生提交。

## Props

非空 href 优先渲染 anchor；否则 clickable/onClick 渲染 button。title、description、prefix、extra、suffix 保留数值 0。disabled/loading anchor 保留节点和 link role，但移除 href 与 Tab stop；loading 显示 spinner、设置 `aria-busy`，并用 `loadingLabel` 或 ConfigProvider locale 提供状态名称。调用方原有 `role` / `aria-busy` 类型入口继续保留：非 loading 时照常透传；unavailable anchor 强制 link role，loading 强制 `aria-busy=true`。arrow 默认按可交互性显示，loading 时由 spinner 替代。

## Events

沿用原生 onClick。disabled/loading button 不派发；disabled/loading anchor 阻止默认与冒泡，也不调用业务回调。

## Ref 与命令式方法

ref 指向实际 `HTMLAnchorElement | HTMLButtonElement | HTMLDivElement`；无额外命令式 API。

## 键盘操作

Tab 只到达非 disabled/loading anchor/button；Enter 激活二者；Space 激活 button，anchor 保持浏览器原生滚动行为。

## 触摸与手势

交互行最小高度 56px，使用原生点击，不拦截页面滚动或实现滑动动作。

## 无障碍

在 List 中 frame 提供 listitem，真实节点保留原生链接/按钮语义。箭头和 spinner 图形隐藏；loading status 使用 polite live region 并允许业务覆盖名称。业务槽位中的语义内容会参与 accessible name。

## 动效

只使用短暂背景/颜色反馈和 loading spinner；reduced-motion 停止 spinner 并压缩过渡，不影响语义。无位移或高度动画。

## 主题与定制

使用 surface/subtle/ink/muted/border token；forced-colors 使用系统边界。逻辑间距支持 RTL。

## SSR 与 Next.js

根据 props 确定性输出原生节点；Next 路由可在业务适配层使用 href 或点击导航，不依赖 next/navigation。

## RTL 与国际化

prefix/suffix/arrow 使用逻辑端布局；默认箭头由显式 Cell `dir="ltr"/"rtl"` 或最近的 ConfigProvider 决定，不依赖新内核的 `:dir()`。组件无内置可见业务文案。loading status 默认跟随最近的 ConfigProvider locale 输出中文或英文；仅当父级已有等价公告时，才应传 `loadingLabel=""` 显式静默。

## 浏览器与 WebView

完整支持矩阵为 Android Chrome/WebView 89+、iOS Safari/WKWebView 15+。Chrome/WebView 70+ 与 iOS 13+ 仅用于构建产物旧语法静态扫描，不代表完整运行时承诺；Chromium/WebView 79–88 与 iOS 13–14 属观察档。forced-colors 使用系统 GrayText 保持 spinner 可见。

## 边界情况与已知限制

key/路由身份由父列表管理；超长文本允许换行。自定义复杂 slot 需避免破坏整行唯一交互目标原则。loading 只阻止激活，不拥有 Promise、取消、重试或超时策略。

## 性能预算

O(1) DOM，无测量、Observer 或监听；大量行应结合 VirtualList。
