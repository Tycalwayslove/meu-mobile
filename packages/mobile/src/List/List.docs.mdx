# List

## 当前能力

List 提供具名 `role=list`、header/footer、plain/card 表面和三种分隔线，并组合独立文档化、支持 loading 的 Cell。开发构建会诊断缺少 listitem 语义的直接子节点，以及整行交互 Cell 内的嵌套交互内容；生产 DOM 与事件不受诊断影响。

## 何时使用

用于账户设置、订单摘要和信息分组等移动端行列表。整行导航使用 href；即时动作使用 onClick；纯展示保持静态。

## 何时不要使用

大量数据虚拟化使用 VirtualList；选择表单使用 Radio/Checkbox/Selector。交互 Cell 内不得再嵌套链接、按钮或表单控件。

## 结构与状态

`root → header? + body[role=list] → frame[role=listitem] → a|button|div + divider + footer?`。Cell 有 static、interactive、disabled、loading、active press 与 focus；List 有 plain/card 与 inset/full/none。

## 基础用法

```tsx
<List header="账户" mode="card">
  <Cell title="地址" href="/address" />
</List>
```

## 受控与非受控

List 没有内部业务状态。Cell 的 `loading` 由调用方控制；组件只负责锁定交互和呈现状态，不拥有异步请求。

## 表单集成

action Cell 默认 `type=button`，不会意外提交表单；显式传 `type=submit` 才参与提交。List 不生成 name/value/FormData。

## Props

API 由 `ListProps` / `CellProps` 生成。非空 href 优先为 anchor；否则 clickable/onClick 为 button。header、footer、description、prefix、extra、suffix 保留数值 0。`aria-label` 优先于 header 的自动 `aria-labelledby`；显式 `aria-describedby` 会落在真正的 `role=list` body。Cell 的 `loading/loadingLabel` 提供本地化忙碌状态并阻止重复激活。扩展行必须显式提供 `role="listitem"`；Fragment 会在开发期检查时展开，不产生额外 DOM。

## Events

Cell 沿用原生 onClick。disabled/loading button 不派发；disabled/loading anchor 保留 anchor 节点和 link role，但移除 href/Tab stop、阻止默认行为和冒泡，也不调用业务 onClick。loading 结束后由调用方恢复导航或动作。

## Ref 与命令式方法

List ref 指向外层 div；Cell ref 是实际 a/button/div。无额外命令式 API。

## 键盘操作

| 按键  | 行为                                    |
| ----- | --------------------------------------- |
| Tab   | 只到达非 disabled/loading anchor/button |
| Enter | 激活 anchor 或 button                   |
| Space | 激活 button；anchor 遵守浏览器滚动规则  |

## 触摸与手势

交互行最小高度 56px；使用原生点击，不拦截滚动或实现滑动。

## 无障碍

body 与 Cell frame 提供 list/listitem；真实交互节点保留原生语义。header 自动命名 list，外部说明可用 `aria-describedby` 关联。空 List 仍保留具名 list，不伪造 listitem、busy 或 status；loading/ready/reorder 更新保持同一个 list 语义根。箭头与 spinner 图形隐藏；loading 通过本地化 polite status 和 `aria-busy` 暴露。自定义前后槽内容若传语义节点会进入 accessible name。

## 动效

仅交互背景色过渡和 loading spinner；reduced-motion 将过渡降到 1ms 并停止 spinner，不使用入场/退场动画。

## 主题与定制

使用 surface/ink/muted/border/accent 与 spacing/radius/motion Token。forced-colors 保留焦点/边界。稳定入口为 mode/divider/className/style 与 data 属性；内部 class 非 API。

## SSR 与 Next.js

useId 只用于 header 关联且 SSR/hydration 稳定；无 effect/browser API。空列表可服务端输出并原位 hydrate，后续填充静态行、anchor 和 button 时保持同一个 `role=list` 节点；loading link hydrate 后恢复 href 也不更换 anchor。Next Link 可通过业务组合，不由组件导入路由库。

## RTL 与国际化

间距、分隔线、文本对齐使用逻辑属性；默认 chevron 由显式 Cell `dir="ltr"/"rtl"` 或最近的 ConfigProvider 决定，不依赖新内核的 `:dir()`。可见业务文案由调用方提供；Cell 内置 loading status 会跟随最近的 ConfigProvider locale 输出中文或英文。仅当外层已有等价 live region 时，才应传 `loadingLabel=""` 显式静默。

## 浏览器与 WebView

完整支持矩阵为 Android Chrome/WebView 89+、iOS Safari/WKWebView 15+。Chrome/WebView 70+ 与 iOS 13+ 仅用于构建产物旧语法静态扫描，不代表完整运行时承诺；Chromium/WebView 79–88 与 iOS 13–14 属观察档。默认箭头方向由配置/显式 prop 生成 class，不依赖 `:dir()`。

## 边界情况与已知限制

开发构建会递归展开 Fragment，检查每个直接子节点是 Cell 或显式 `role=listitem`，但不会猜测自定义组件最终渲染出的角色，也不会自动补 listitem。整行可点击 Cell 的 title/description/prefix/extra/suffix/arrow 中若出现原生控件、交互 role、href/onClick、contentEditable 或可顺序聚焦节点会告警；复杂尾部控件应放在静态 Cell。该诊断不在 production 执行，且不改变 DOM。Cell 空 href 不视为导航。loading 不启动、取消或重试请求；调用方必须在 Promise settle、路由失败和卸载路径中收敛状态。

## 性能预算

无监听或测量，节点 O(children)。超长集合应改用虚拟化。
