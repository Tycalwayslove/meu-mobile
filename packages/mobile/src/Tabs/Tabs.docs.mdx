# Tabs

## 当前能力

完整 APG tablist/tab/tabpanel，支持 automatic/manual 激活、禁用跳过、Arrow/Home/End、RTL、滚动入视与双边溢出提示、受控/非受控及三种 panel 挂载策略。

## 何时使用

用于同一页面内同层级内容切换，标签数量应保持可扫描。

## 何时不要使用

一级路由使用 TabBar；步骤流程使用 Steps；大量动态筛选项使用 Selector。

## 结构与状态

`root → tablist → button[role=tab] + tabpanel`。状态为 active、inactive、disabled、focused；DOM id 由 useId 稳定关联。

## 基础用法

```tsx
<Tabs aria-label="账户" items={[{ key: "profile", label: "资料", content: <Profile /> }]} />
```

## 受控与非受控

传 `value`（含 null）即受控；否则从有效 `defaultValue` 或首个 enabled item 初始化。无效或禁用的受控值不选择 panel，但首个 enabled tab 仍保留 roving focus。外部改变受控值且焦点不在 tablist 内时，新选中项成为下一次 Tab 进入点；manual 模式在列表内移动焦点时，焦点项可暂时与选中项不同。非受控当前项被删除或禁用时会永久归一到首个 enabled item。组件挂载后不要在受控与非受控模式之间切换。

## 表单集成

不适用：Tabs 是内容导航，不提交表单值；tab button 固定 type=button。

## Props

| Prop              | 类型                   | 默认值        | 契约                                                                   |
| ----------------- | ---------------------- | ------------- | ---------------------------------------------------------------------- |
| `items`           | `readonly TabsItem[]`  | 必填          | 有序项；`key` 必须唯一、稳定，支持任意字符串；`disabled` 不可激活/聚焦 |
| `value`           | `string \| null`       | `undefined`   | 受控 active key；`null`、无效或 disabled key 表示无选中项              |
| `defaultValue`    | `string`               | 首个 enabled  | 仅用于非受控初始化；无效值回退到首个 enabled                           |
| `activationMode`  | `automatic \| manual`  | `automatic`   | 方向键随焦点自动激活，或等待 Enter/Space                               |
| `lazy`            | `boolean`              | `false`       | panel 首次 active 时挂载，之后保留                                     |
| `destroyInactive` | `boolean`              | `false`       | inactive panel 卸载；优先于 `lazy`，会丢失 panel 内部状态              |
| `stretch`         | `boolean`              | `true`        | 平分可用宽度；`false` 使用内容宽度并允许横向滚动                       |
| `aria-label`      | `string`               | 内置中/英文名 | 建议提供业务名称；也可用 `aria-labelledby`                             |
| `onChange`        | `(key, event) => void` | —             | 新 enabled key 的激活请求                                              |
| `ref`             | `Ref<HTMLDivElement>`  | —             | React 19 根节点 ref                                                    |

其余 root `div` 属性可透传，但 `children/defaultValue/onChange` 使用组件专用契约。

## Events

`onChange(key,event)` 在点击、automatic 方向键或 manual Enter/Space 请求激活“不同的新 key”时发出；disabled 或当前 key 不触发。受控状态不乐观改变，由调用者回写 `value`。事件为触发按钮的 React mouse/keyboard event。

## Ref 与命令式方法

ref 指向根 div，支持 React 19 `ref` prop 与对象/回调 ref；不公开命令式切换方法，使用 `value` 控制选择，使用原生 `focus()` 只移动焦点。

## 键盘操作

| 按键                   | 行为                                        |
| ---------------------- | ------------------------------------------- |
| ArrowLeft / ArrowRight | 循环移动焦点并跳过 disabled；RTL 镜像       |
| Home / End             | 首个/末个 enabled tab                       |
| Enter / Space          | manual 模式激活聚焦项                       |
| Tab                    | 从 tablist 的单一 roving tab stop 进入/离开 |

## 触摸与手势

每个 tab 高度至少 48px；横向列表原生滚动，不拦截滑动。左右物理边缘仅在该方向仍有被裁切 tab 时显示渐隐提示；ResizeObserver 跟踪容器/标签尺寸，缺失时回退到 window resize。键盘和点击激活会把目标滚入最近可见区域。

## 无障碍

tablist 有名称和 horizontal orientation；tab 与 panel 通过 aria-controls/aria-labelledby 双向关联；aria-selected 与 roving tabindex 同步；disabled 使用原生 disabled 并从方向键序列移除。全 disabled 时没有 tab stop，也没有 active panel。forced-colors 下取消渐隐 mask、恢复原生滚动条，并以系统色表达 tab/active 状态。

## 动效

指示器仅 opacity/transform；reduced-motion 缩短到 1ms，切换不会等待动画。

## 主题与定制

使用 accent/muted/border token；forced-colors 提供边框与 Highlight。内部 class 不是 API。

## SSR 与 Next.js

useId 保持单次 SSR/hydration 的关联稳定；lazy SSR 只输出首个 active panel。溢出属性以 `false` 输出，hydration 后再测量，不制造服务端/客户端结构差异。首屏 items/value 必须一致，避免调用方造成 hydration mismatch。

## RTL 与国际化

左右键优先使用最近显式 `dir=ltr|rtl` 祖先，否则使用 ConfigProvider；局部 LTR 可覆盖外层 RTL。滚动与双边提示按物理可见边缘测量，不依赖各浏览器不同的 RTL `scrollLeft` 模型。默认 tablist 名称支持中英文。

## 浏览器与 WebView

完整支持矩阵为 Android Chrome/WebView 89+、iOS Safari/WKWebView 15+；Chrome/WebView 70+ 与 iOS 13+ 仅是源码/构建产物的旧语法扫描基线，不代表完整运行时承诺。iOS 13–14、Chromium/WebView 79–88 属观察档，仍待运行时抽测。`scrollIntoView`、ResizeObserver 不可用时分别降级为不自动入视、window resize 重测，选择与键盘契约不受影响。

## 边界情况与已知限制

item.key 必须唯一稳定。内部 ref 使用 Map，因此 `__proto__` 等任意字符串不会发生对象原型碰撞，删除项也会释放节点引用。动态删除 item 会清理其访问身份；同 key 后续再出现按新 panel 处理。销毁 inactive panel 会丢失未提升的输入/滚动状态；lazy 保留可能增加长期 DOM，应按内容成本选择。

## 性能预算

每次 render 的选择、enabled、visited 归一为 O(items)；一个 ResizeObserver 观察 tablist 与 tab 节点，不为每项创建 observer。默认 panel DOM 为 O(items)，lazy 可延迟昂贵内容但不自动回收，destroyInactive 将 panel DOM 限制为 O(1)。
