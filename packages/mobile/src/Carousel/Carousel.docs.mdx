# Carousel

## 当前能力

- Embla 驱动的单页轮播，支持受控/非受控 index、drag、loop、gap、indicator 和可选 autoplay。
- 固定提供前后原生按钮；autoplay 时在顶部居中提供暂停/播放按钮，与两侧导航保持独立的 44×44 触控区。hover 和页面隐藏只暂时挂起计时，focus、drag 和前后按钮会持续暂停，直到用户显式播放。
- 独立 live status 始终组合自定义页名、可见页和总页数；自动轮播时关闭公告，静止后的换页使用 polite 公告。
- `onIndexChange` 区分 `autoplay | drag | next | previous`；非活动页从焦点顺序移除。

## 何时使用

用于商品横幅、内容推荐、媒体画廊和有限页引导。重要内容不应只存在于自动轮播中。

## 何时不要使用

长列表使用横向 List/VirtualList；步骤流程使用 Steps；不使用轮播隐藏必须阅读的条款或关键操作。

## 结构与状态

root → controls → viewport/track/slides → indicator。状态包括 active index、dragging、rotating、paused、disabled、reduced-motion；视觉设计不应把瞬时运行时状态全部伪造成 variants。

## 基础用法

```tsx
<Carousel
  aria-label="活动推荐"
  items={banners.map((item) => ({
    key: item.id,
    ariaLabel: item.title,
    content: <Banner {...item} />
  }))}
/>
```

## 受控与非受控

受控使用 `index/onIndexChange`，非受控使用 `defaultIndex`。输入会归一化到现有 item 范围；受控调用方未更新 index 时，视图会回滚到受控值。不要在同一实例运行时切换是否传入 `index`，如需切换请使用新的 `key`。

items 初始为空时，非受控 Carousel 会在首批内容到达后应用首次 `defaultIndex`。现有 items 缩短时，索引立即收敛；随后扩容不会复活已裁掉的旧索引。items 归一化和受控 prop 更新都不触发 `onIndexChange`。

## 表单集成

不适用。Carousel 不应作为隐式表单字段；需要选择语义时使用 Selector 或 RadioGroup。

## Props

API 表由 `CarouselProps` 生成。核心为 items、index/defaultIndex、onIndexChange、allowDrag、loop、autoplay、autoplayInterval、indicator、gap 与可访问 label props。

## Events

`onIndexChange(index, { reason })` 只在用户操作或 timer 选中不同页时触发。drag 开始会持续暂停本轮 autoplay，前后按钮和焦点进入也会暂停；hover 与页面隐藏只挂起当前 timer。Embla `reInit` 和 props/items 归一化不伪装成 drag 事件。

## Ref 与命令式方法

ref 指向根 `HTMLDivElement`。React 19 回调 ref 的 cleanup 会原样执行，传统回调 ref 在卸载时收到 null，且普通重渲染不会反复解绑/重绑。不公开 Embla instance；程序化切换通过受控 index 完成。

## 键盘操作

| 按键          | 行为                                      |
| ------------- | ----------------------------------------- |
| Tab           | 进入暂停/播放、上一张、下一张和当前页内容 |
| Enter / Space | 触发对应原生按钮                          |

当前不在根节点劫持方向键，避免与页面滚动冲突。

## 触摸与手势

drag 默认开启，阈值由 Embla 控制。track 使用 `touch-action: pan-y pinch-zoom`，浏览器保留纵向滚动和缩放；Embla 8.6.0 负责横向识别、多指退出和 `touchcancel`。组件监听 Embla `pointerUp` 清除未完成 drag 的原因，不自行持有 pointer capture。

Unit 只能验证事件订阅和清理，不能模拟 WebView 的手势仲裁。横向拖动、斜向起手、纵向滚动、多指缩放、系统取消、嵌套链接和 RTL 方向仍需目标浏览器与真机验证。

## 无障碍

提供 carousel/slide roledescription、每页名称、独立位置 status、暂停控制和前后按钮。自定义 `ariaLabel` 不再遮蔽页码：status 会公告“页名，第 2 张，共 5 张”。自动轮播时 status 为 `aria-live=off`；静止时为 polite。非活动页同时使用 `aria-hidden` 与 `inert`；旧内核 fallback 保存/恢复调用方 tabindex，并观察动态插入与 tabindex/disabled/href/contenteditable 变化，避免新控件进入隐藏页的 Tab 路径。

## 动效

默认不自动播放。系统 `prefers-reduced-motion` 或 `ConfigProvider motion="reduced"` 时自动播放不启动；用户显式播放后使用即时切换。暂停按钮获焦时会先停止轮播，但仍保留“暂停”动作，后续 click/Enter 不会反向重启。V2 仍需验证真实动画中断、controlled rollback 和 loop clone 的视觉边界。

## 主题与定制

稳定入口为 indicator renderer/variant、gap、items content 和全局 Token。Embla DOM/class 不是公开 API。

## SSR 与 Next.js

服务端输出静态 slides、原生按钮、活动/非活动语义和位置 status，不访问 window/document。交互在客户端初始化。items 的 key、数量和初始 index 在 hydration 前必须稳定。共置 hydration 测试验证受控第二页、reduced-motion autoplay、三页 inert/焦点隔离和 status 在接管前后保持一致，0 recoverable/console error。

## RTL 与国际化

内置中英文按钮与 roledescription。`dir=rtl` 会传给 Embla，按钮位置和图标使用逻辑方向；Unit 与 `RtlAndLongContent` Story 覆盖配置和长文本。真实手势方向与双向文本仍需目标浏览器验证。

## 浏览器与 WebView

依赖 Pointer/Touch、MutationObserver、matchMedia、visibility API 和 Embla。必须在目标 iOS/Android WebView 验证；matchMedia 已有 addListener fallback。

## 边界情况与已知限制

- items 为空或只有一项时控制按钮禁用。
- autoplay 最短间隔归一为 1000ms，但内容可读时间仍由调用方负责。
- MutationObserver 仅扫描 slide 内潜在焦点节点及相关属性；复杂动态内容仍需性能验证。
- 前后按钮、顶部居中的 autoplay 控制和 indicator 覆盖在内容上方。紧凑 slide 的播放控制不会再与两侧导航重叠，但业务内容仍应预留顶部 56px、两侧至少 64px，并在 200% 字体下检查换行；组件无法替业务内容自动腾出安全区。

## 性能预算

普通轮播建议保持有限 slides；超大列表不属于本组件。V2 记录 50 slides/复杂卡片基准、主线程长任务和增量 gzip。

- Unit/SSR/hydration: Carousel 目录 3 个测试文件共 23 项通过。覆盖默认静止、位置公告、原生按钮键盘路径、受控回滚与 slides 缩短、空→加载→缩短→扩容、loop、关闭 drag、gap 归一、autoplay focus/hover/visibility/reduced-motion、drag reason、RTL、React 19/传统 callback ref、资源清理，以及非活动页动态控件的 inert/tabindex 隔离与恢复。
- SSR: `Carousel.ssr.test.tsx` 在无 window/document 环境验证静态按钮、默认关闭 autoplay、活动索引、inactive/inert 和页名/页数 status。
- Hydration: `Carousel.hydration.test.tsx` 验证 controlled index=1、reduced-motion autoplay 首屏、三页 slide/status 语义、inactive link `tabIndex=-1` 与 active button 可聚焦，React recoverable error 与 console error 均为 0。
- Story interaction: `Default` 验证前进按钮、索引更新与活动 slide；`AccessibleAutoplayPause` 验证暂停按钮的 focus→click 路径和静止 live status；`RtlAndLongContent` 新增 RTL、长文案无横向溢出、44×44 原生按钮、不重叠和活动页换行断言。当前 6 个 Story；新增 play 随主流程统一重建后复验。
- Carousel 定向浏览器扫描：6 个 Story × Light/Dark 两个场景全部通过；play 返回 success，axe WCAG A/AA 为 0 违规，且无 `pageerror`。
