# Carousel

## 当前能力

- Embla 驱动的单页轮播，支持受控/非受控 index、drag、loop、gap、indicator 和可选 autoplay。
- 固定提供前后原生按钮；autoplay 时提供暂停/播放按钮，并在 hover、focus、页面隐藏和 drag 时暂停。
- `onIndexChange` 区分 `autoplay | drag | next | previous`；非活动页从焦点顺序移除。

## 何时使用

用于商品横幅、内容推荐、媒体画廊和有限页引导。重要内容不应只存在于自动轮播中。

## 何时不要使用

长列表使用横向 List/VirtualList；步骤流程使用 Steps；不使用轮播隐藏必须阅读的条款或关键操作。

## 结构与状态

root → controls → viewport/track/slides → indicator。状态包括 active index、dragging、rotating、paused、disabled、reduced-motion；视觉设计不应把瞬时运行时状态全部伪造成 variants。

## 基础用法

```tsx
<Carousel
  aria-label="活动推荐"
  items={banners.map((item) => ({
    key: item.id,
    ariaLabel: item.title,
    content: <Banner {...item} />
  }))}
/>
```

## 受控与非受控

受控使用 `index/onIndexChange`，非受控使用 `defaultIndex`。输入会归一化到现有 item 范围；受控调用方未更新 index 时，视图会回滚到受控值。

## 表单集成

不适用。Carousel 不应作为隐式表单字段；需要选择语义时使用 Selector 或 RadioGroup。

## Props

API 表由 `CarouselProps` 生成。核心为 items、index/defaultIndex、onIndexChange、allowDrag、loop、autoplay、autoplayInterval、indicator、gap 与可访问 label props。

## Events

`onIndexChange(index, { reason })` 只在实际选择变化时触发。drag 开始会永久暂停本轮 autoplay，前后按钮也会暂停；hover 只是暂时暂停。

## Ref 与命令式方法

ref 指向根 `HTMLDivElement`。不公开 Embla instance；程序化切换通过受控 index 完成。

## 键盘操作

| 按键          | 行为                                      |
| ------------- | ----------------------------------------- |
| Tab           | 进入暂停/播放、上一张、下一张和当前页内容 |
| Enter / Space | 触发对应原生按钮                          |

当前不在根节点劫持方向键，避免与页面滚动冲突。

## 触摸与手势

drag 默认开启，阈值由 Embla 控制；必须验证横向手势与纵向页面滚动、pointer cancel、多指、嵌套可点击内容和 RTL。

## 无障碍

提供 carousel/slide roledescription、每页名称、live region、暂停控制和前后按钮。非活动页同时使用 `aria-hidden` 与 `inert`；旧内核 fallback 保存/恢复调用方 tabindex，并观察动态插入与 tabindex/disabled/href/contenteditable 变化，避免新控件进入隐藏页的 Tab 路径。

## 动效

默认不自动播放。reduced-motion 时自动播放不启动，用户显式播放后使用即时切换。V2 需验证动画中断、controlled rollback 和 loop clone 的可见性。

## 主题与定制

稳定入口为 indicator renderer/variant、gap、items content 和全局 Token。Embla DOM/class 不是公开 API。

## SSR 与 Next.js

服务端输出静态 slides，交互在客户端初始化。items 的 key、数量和初始 index 在 hydration 前必须稳定。

## RTL 与国际化

内置中英文按钮与 roledescription。V2 需验证 RTL 下视觉顺序、手势方向、前后按钮图标和 Embla direction 配置。

## 浏览器与 WebView

依赖 Pointer/Touch、MutationObserver、matchMedia、visibility API 和 Embla。必须在目标 iOS/Android WebView 验证；matchMedia 已有 addListener fallback。

## 边界情况与已知限制

- items 为空或只有一项时控制按钮禁用。
- autoplay 最短间隔归一为 1000ms，但内容可读时间仍由调用方负责。
- MutationObserver 仅扫描 slide 内潜在焦点节点及相关属性；复杂动态内容仍需性能验证。

## 性能预算

普通轮播建议保持有限 slides；超大列表不属于本组件。V2 记录 50 slides/复杂卡片基准、主线程长任务和增量 gzip。

## 测试证据

- Unit: `Carousel.test.tsx` 覆盖语义、受控回滚、自动播放/reduced-motion、可见性、drag reason，以及非活动页动态控件的 inert/tabindex 隔离与恢复。
- Story interaction: `Default` 验证前进按钮、索引更新与活动 slide 的可访问状态；`check-storybook-links` 已验证全库 80/80 title 各至少一项关键 play，本 title 的 play 在本地扫描中返回 `storyFinished=success`。
- Storybook 浏览器矩阵：本地扫描器在 390×844 视口验证 374 个 Story × 7 场景（Light、Dark、en-US、RTL、reduced-motion、200% 字体、forced-colors），共 2,618 个组合；有 play 的 Story 必须先返回 `storyFinished=success`，再运行 axe WCAG A/AA，结果为 0 违规、0 `pageerror`。
- 官网 Next 运行时：本地 production build 在 390×844 下逐页验证 68 个组件页的 Light/Dark（136 场景）；主题恢复、H1/预览/API 结构、React `pageerror` / `console.error`（含 hydration mismatch）和 axe WCAG A/AA 均通过。
- Bundle：Rollup tree-shaken ESM（React 与包 peer dependencies external）单一公开值 gzip 18395 B / 49152 B 预算，组合 Brotli 16225 B；共享样式由应用单独导入一次。
- SSR/hydration: 隔离 Next 16 App Router hydration 后受控索引、活动/非活动 slide 及原生替代操作保持一致，0 hydration/runtime error
- RTL: 待补
- Reduced motion: 有单测覆盖，待真实浏览器证明
- Mobile Chromium/WebKit E2E: `runs the controlled carousel with native alternatives and focus isolation` 在两种引擎断言前后按钮、受控索引、slide 名称、非活动控件 `tabindex=-1` 与活动 link 可聚焦；drag/滚动竞争仍待专项
- Chromatic Light/Dark: Figma 与 stories 已有基线，待矩阵化
- Real device: 待补
