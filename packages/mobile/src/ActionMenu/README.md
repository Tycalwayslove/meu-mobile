# ActionMenu

Accessible mobile action sheets built on Meu Popup. Action items are native buttons inside a modal dialog, with controlled and uncontrolled state, focus restoration, scroll locking, async action handling, and a provider-scoped imperative API.

Danger actions are always moved into a separate group and confirmed through Dialog. Use ActionMenu for a short list of contextual actions; use Picker for selection and BottomSheet for longer task flows.
