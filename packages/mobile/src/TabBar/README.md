# TabBar

2–5 个一级页面入口的底部导航原语。非空 `href` 保持原生 anchor，无 `href` 使用 `type="button"`；受控路由、禁用、Badge、动态 identity、焦点接管、RTL、横屏与 Safe Area 均有明确契约。
