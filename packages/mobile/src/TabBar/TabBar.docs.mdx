# TabBar

## 当前能力

2–5 个一级目的地导航；href 使用原生 link，无 href 使用 button。支持 aria-current、受控路由、Badge 名称、安全区、禁用、横屏与 active-aware icon。

## 何时使用

用于移动 H5 的稳定一级页面入口。

## 何时不要使用

页面内部内容切换使用 Tabs；瞬时操作不要伪装成目的地；超过五项改用菜单或信息架构调整。

## 结构与状态

`nav → items → a|button → decorative icon + label`，可选 Badge 与底部 SafeArea。状态为 current、idle、disabled、pressed、focus-visible。

## 基础用法

```tsx
<TabBar value={route} items={routes} onChange={(key) => navigate(key)} safeArea />
```

## 受控与非受控

`value !== undefined` 时受控，null 或无效/禁用 key 表示无当前页；非受控从有效 defaultValue 或首个 enabled item 初始化。当前项被删除或禁用时会永久归一到首个 enabled item。路由框架应使用受控模式。

## 表单集成

不适用：button 固定 type=button，导航不会提交祖先 form。

## Props

item.href 决定 link/button；disabled href 会降为原生 disabled button。`badgeLabel` 为读屏补充未读/待办含义，`ariaLabel` 可覆盖整项名称。

## Events

item.onClick 先执行；调用 `event.preventDefault()` 会同时取消选择请求与链接导航。未取消时，`onChange(key,event)` 仅在新 enabled 项请求成为 current 时触发。

## Ref 与命令式方法

ref 指向 nav；无命令式路由 API。

## 键盘操作

| 按键            | 行为                                |
| --------------- | ----------------------------------- |
| Tab / Shift+Tab | 按 DOM 顺序遍历 enabled link/button |
| Enter           | 激活 link 或 button                 |
| Space           | 激活 button；link 保持原生行为      |

## 触摸与手势

每项至少 44px 高并均分宽度；无滑动或长按手势。

## 无障碍

nav 必须有名称；当前目的地使用 aria-current=page；icon aria-hidden；Badge 可通过 badgeLabel 提供状态含义；禁用项使用原生 disabled。

## 动效

颜色过渡使用 motion token；reduced-motion 缩短到 1ms。

## 主题与定制

使用 surface/border/muted/accent token；forced-colors 使用 LinkText/ButtonText/Highlight。

## SSR 与 Next.js

纯确定性 nav。Next Link 可由上层包装/路由适配，核心不依赖 next/navigation；首屏 value/items 应一致。

## RTL 与国际化

flex 顺序继承 dir；路由 key 不本地化，label/ariaLabel/badgeLabel 由业务翻译。默认 nav 名称支持中文/英文。

## 浏览器与 WebView

原生 link/button 与 flex，兼容 Chrome/WebView 70+、iOS 13+；横屏低高度保持至少 44px。

## 边界情况与已知限制

item.key 必须唯一。动态删除/禁用当前非受控项会清理旧身份，重新加入时不会意外跳回。组件不 fixed、不拥有浏览历史或路由 pending；异步导航失败时受控 value 应保持原路由。

## 性能预算

O(items)，建议最多五项；无监听、测量和第三方运行时。

## 测试证据

- Unit: link/button、current、controlled null、动态 remove/disable 归一、可取消点击、Badge 名称、安全区和 locale
- Story interaction: `RouteInteraction` 验证 button route 的当前态切换；仓库门禁 `check-storybook-links` 本地验证 `play-fn 80/80`（80 个 Storybook title 均至少一个有意义 play）。
- Storybook 浏览器矩阵：本地扫描器在 390×844 视口验证 374 个 Story × 7 场景（Light、Dark、en-US、RTL、reduced-motion、200% 字体、forced-colors），共 2,618 个组合；有 play 的 Story 必须先返回 `storyFinished=success`，再运行 axe WCAG A/AA，结果为 0 违规、0 `pageerror`。
- 官网 Next 运行时：本地 production build 在 390×844 下逐页验证 68 个组件页的 Light/Dark（136 场景）；主题恢复、H1/预览/API 结构、React `pageerror` / `console.error`（含 hydration mismatch）和 axe WCAG A/AA 均通过。
- Bundle：Rollup tree-shaken ESM（React 与包 peer dependencies external）单一公开值 gzip 3675 B / 32768 B 预算，组合 Brotli 3255 B；共享样式由应用单独导入一次。
- SSR/hydration: `TabBar.ssr.test.tsx`
- RTL: 原生 flex 继承，视觉待补
- Reduced motion: CSS 实现
- Mobile Chromium/WebKit E2E: `connects tab panels, primary navigation and read-only progress semantics` 在两种引擎断言 navigation、原生 link、button 当前态、badge 名称、disabled 与 44px 目标
- Chromatic Light/Dark: 发布后建立
- Real device: 待补
