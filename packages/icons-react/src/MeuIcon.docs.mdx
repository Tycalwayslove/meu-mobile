# Icon

## 当前能力

- `@meu/icons-core` 提供 5 个平台无关 SVG node，`@meu/icons-react` 提供通用 `MeuIcon` 与 Meu 命名组件；Meu 名称是稳定 API，不表示 Meu 创作了几何。
- 所有图标使用 24 × 24 viewBox、`currentColor`、圆角端点，默认 `size=24`、`strokeWidth=2`。
- 无 accessible name 时默认为装饰图并设置 `aria-hidden`；可用 `title`、`aria-label` 或 `aria-labelledby` 创建语义图。title-only 模式用 React `useId` 建立真实 `title` 关联，SSR 与 hydration 保持一致。
- 几何逐字生成自 `lucide-static@1.34.0` 的 5 个已锁定 SVG；lock 固定 npm SHA-512、Lucide commit、逐文件/逐几何 SHA-256、上游名称和 React 导出。
- 仓库随包保留 Lucide 完整 LICENSE、Feather MIT 文本、上游 SVG snapshot 与逐图标 manifest；生成和漂移检查不访问网络。
- `legal:check` 校验仓库、图标包和官网公开许可副本一致，并对实际 `npm pack --dry-run` 文件清单断言 notices、许可、lock、manifest 与上游 SVG 均随制品保留；官网 `/licenses` 提供公开披露入口。

当前工程来源链已验证；商用分发义务仍需法务复核，组件状态因此保持 `verification`。

## 何时使用

用于按钮、导航、状态或短标签旁的辅助图形。交互操作应由 Button、IconButton 或链接承载，图标只负责视觉表达。

## 何时不要使用

- 不把裸 SVG 图标当作可点击控件。
- 不用图标替代必须阅读的业务文案、错误原因或金额信息。
- 品牌 Logo、商标和业务专属资产不能直接加入基础图标集，必须单独登记权利来源。

## 结构与状态

结构为一个 `svg` 和静态几何节点。图标本身没有 pressed、disabled、loading 等交互状态；颜色和状态由拥有它的控件通过 `currentColor` 传递。

## 基础用法

```tsx
<button type="button">
  <MeuIconSearch aria-hidden />
  搜索
</button>

<MeuIconCheck title="操作成功" size={20} />
```

## 受控与非受控

不适用。图标不持有状态。

## 表单集成

不适用。图标不是表单控件，也不会参与 FormData、校验或提交。

## Props

通用 `MeuIcon` 需要 `icon` 和稳定 kebab-case `name`；命名图标已经固化这两项。`size` 同时控制宽高，`strokeWidth` 使用 24 × 24 坐标系单位；其余属性来自原生 `SVGProps`。名称优先级为非空 `aria-label` → 非空 `aria-labelledby` → 非空 `title`；空白名称不会把装饰图误升格为语义图。

## 来源与再生成

`@meu/icons-core/icons.lock.json` 是人工评审入口，记录 Meu ID → Lucide 名称 → React 导出的映射。`icons:generate` 从仓库内已校验的上游 SVG snapshot 生成 TypeScript 与 manifest；`icons:check` 离线比较生成结果，已接入 core package Unit。显式的 `icons:upstream:verify` 才会联网，它先验证固定 npm 归档 SHA-512，再只读比较 snapshot；网络或 checksum 失败都会退出，不会替换文件。

```sh
pnpm --filter @meu/icons-core icons:generate
pnpm --filter @meu/icons-core icons:check
pnpm --filter @meu/icons-core icons:upstream:verify
pnpm legal:check
```

## Events

透传原生 SVG 事件，但不建议直接在图标上承载交互。事件、disabled 和触控目标应由拥有图标的控件处理。

## Ref 与命令式方法

ref 指向 `SVGSVGElement`，只提供原生 DOM 能力。

## 键盘操作

| 按键 | 行为                                    |
| ---- | --------------------------------------- |
| 无   | 图标不进入 Tab 顺序；交互由外层控件提供 |

## 触摸与手势

不定义触摸或手势。图标尺寸不等于合格触控目标，图标按钮仍需至少 44 × 44 CSS px 的外层控件。

## 无障碍

默认图标设置 `aria-hidden=true` 和 `focusable=false`。图标单独传达信息时提供 `title`、`aria-label` 或 `aria-labelledby`；title-only 模式输出有稳定 ID 的 `<title>` 并由 `aria-labelledby` 引用。已有相邻可见文案时保持装饰模式，避免重复公告。显式 `aria-hidden=true` 优先于名称输入，并移除竞争的 label、labelledby 与 title 元数据。

## 动效

不提供内建动效，因此没有 reduced-motion 分支。旋转或过渡由拥有图标的组件负责，并必须提供 reduced-motion 降级。

## 主题与定制

稳定定制面为 `currentColor`、`size`、`strokeWidth` 和原生 SVG 属性。`data-meu-icon` 提供稳定语义 ID；内部 path 顺序不是公共样式接口。

## SSR 与 Next.js

输出是确定性的 SVG，不读取浏览器全局、不发起运行时请求，可在服务端渲染。title ID 由 React `useId` 生成，不依赖随机数或 DOM 查询；首次树结构一致时可安全 hydration。交互事件仍要求位于 Client Component 边界。

## RTL 与国际化

图标库不自动镜像。`MeuIconChevronLeft` 只表示物理“向左”几何；“返回、上一项、展开”等语义及 RTL 镜像由 NavBar、Carousel、IconButton 等拥有上下文的组件处理。调用方可在明确的 RTL 业务语义中使用 `transform: scaleX(-1)`，但不能对 check、plus、search、x 等非方向图标做全局镜像。图标不内置可见文案，accessible name 由调用方本地化。

## 浏览器与 WebView

依赖基础 inline SVG、`currentColor` 和 ARIA。完整支持范围沿用 V2 兼容矩阵；旧环境仍需通过真实 WebView 与读屏验证，不以静态语法检查代替运行时结论。

## 边界情况与已知限制

- 当前只有 `chevron-left`、`check`、`plus`、`search`、`x` 5 个图标。
- 当前 5 个 Meu 命名导出分别映射同名 Lucide/Feather 图标，`modified=false`；完整映射和 checksum 以生成 manifest 为准。
- 工程校验只能证明当前 snapshot、生成物和上游归档一致，不能代替律师对 ISC/MIT 通知、发布载体和商业使用场景的最终意见。
- `title` 适合简短名称，不承担长说明或动态状态公告。
- 同时提供 `aria-label` 与 `aria-labelledby` 时 `aria-label` 优先；IconButton 等上层控件会进一步限制为二选一。
- named component 不提供自动 RTL 镜像，调用方不得仅凭图形名称猜测业务方向。

## 性能预算

几何作为静态数组随 ESM 导出，不加载字体、图片或运行时图标网络资源。正式发布前仍需记录逐图标增量 gzip 与 tree-shaking 结果。

- Generation drift: `icons:check` 验证 snapshot/license checksum，并离线比较 `icons.ts` 与 manifest；core package `test` 必须先通过该检查
- Upstream archive: `icons:upstream:verify` 已用固定 npm SHA-512 验证 5 个 SVG 和完整 LICENSE；该显式审计命令不进入普通 `pnpm check`
- Distribution notice: `legal:check` 已校验 5 条逐图标来源记录、仓库/包/官网许可副本一致、官网披露链接，以及 `npm pack --dry-run` 的 LICENSE、notices、许可、lock、manifest 与上游 SVG 文件清单；该门禁已接入根 `pnpm check`
- Story interaction: `Catalog` 验证装饰图标不可聚焦且对辅助技术隐藏；`check-storybook-links` 已验证全库 81/81 title 各至少一项关键 play，本 title 的 play 在本地扫描中返回 `storyFinished=success`。
- Storybook 浏览器矩阵：本地扫描器在 390×844 视口验证 444 个 Story × 7 场景（Light、Dark、en-US、RTL、reduced-motion、200% 字体、forced-colors），共 3,108 个组合；有 play 的 Story 必须先返回 `storyFinished=success`，再运行 axe WCAG A/AA，结果为 0 违规、0 `pageerror`。
- 官网 Next 运行时：本地 production build 在 390×844 下逐页验证 68 个组件页的 Light/Dark（136 场景）；主题恢复、H1/预览/API 结构、React `pageerror` / `console.error`（含 hydration mismatch）和 axe WCAG A/AA 均通过。
- Bundle：Rollup tree-shaken ESM（React 与包 peer dependencies external）6 个公开值组合 gzip 1531 B / 32768 B 预算；最大单值 `MeuIconCheck` 为 1507 B / 32768 B 预算，组合 Brotli 1335 B；共享样式由应用单独导入一次。
- SSR/hydration: Unit 已验证 SSR title/labelledby 关联、角色、Meu ID、currentColor 与尺寸；独立真实 hydration 仍由 Next H5 证据覆盖
- RTL: 规则已文档化，拥有方向语义的上层组件仍需逐项验证
- Reduced motion: 不适用；没有内建动效
- Mobile Chromium/WebKit E2E: Next production consumer 已在双引擎直接验证 `MeuIconSearch` 输出 `data-meu-icon="search"`、装饰态 `aria-hidden=true` / `focusable=false`、20×20 尺寸，并由 44×44 以上 IconButton 经焦点 + Enter 激活；页面 hydration 后保持 0 `pageerror` / `console.error`。语义图标的真实 VoiceOver/TalkBack 公告仍未执行。
- Chromatic Light/Dark: Catalog 与 SemanticIcon Story 可构建，显式 Light/Dark 快照矩阵待补
- Real device: 待补
